# Discover, Segment, and Select：零样本伪装目标分割的渐进式机制

> **论文**：Discover, Segment, and Select: A Progressive Mechanism for Zero-shot Camouflaged Object Segmentation  
> **来源**：CVPR 2026，arXiv:2602.19944  
> **代码**：[ynulonger/DSS](https://github.com/ynulonger/DSS)  
> **本地 PDF**：已下载并导入 Zotero，集合为 `每日精读论文/2026/09/26`。

## 1. 先说结论

这篇论文解决的是一个很具体、也很实用的问题：**没有用伪装目标数据训练过的模型，能不能只靠现成的视觉基础模型，直接把藏在背景里的目标分割出来？**

作者认为，过去的零样本 COD 通常是“两步走”：先让多模态大模型（MLLM）指出目标大概在哪里，再把这个提示交给 SAM 一类的分割模型。问题是，伪装目标本来就和背景相似，MLLM 给出的点、框或粗 mask 经常偏掉；一旦第一步错了，SAM 会很认真地把错误提示分成一个边界漂亮的错误目标。

DSS 的改法不是让 MLLM 一次猜准，而是把流程拆成三个逐步收紧的环节：

1. **FOD** 先用视觉特征生成多个彼此有差异、但与图像结构相容的目标候选；
2. **SAM** 把每个候选提示变成多个精细 mask；
3. **SMS** 再让 MLLM 根据语义和整体场景从候选 mask 中选出最合理的结果。

真正值得学习的不是“又用了 SAM 和 MLLM”，而是把发现、分割、选择解耦：前面允许保留多个假设，后面再用语义判断淘汰错误候选。这种设计很适合伪装目标，因为这类任务最大的风险不是边界画得不够细，而是**一开始就把背景当成目标，或者把目标漏掉**。

## 2. 任务和相关方法脉络

### 2.1 什么是零样本 COD

普通 COD 通常在 COD10K、CAMO 等数据集上训练，模型见过大量“目标和背景高度相似”的例子。零样本 COD 则不使用目标分割标注进行训练，测试时直接调用通用视觉模型。输入只有一张图，输出是伪装目标的像素 mask。

它比普通显著目标分割难，因为目标不一定颜色突出、边缘明显或面积较大。模型需要利用形状、局部纹理、物体完整性和场景语义的组合证据。

### 2.2 过去的 discover-then-segment 为什么容易失败

MLLM 擅长回答“图中有什么”，但未必擅长精确地指出伪装目标的每个像素。它可能出现三种错误：

- **定位漂移**：点或框落在目标旁边的背景上；
- **漏检**：目标太小、太像背景或图像中有多个目标时，模型只说出其中一个；
- **语义幻觉**：模型根据常见场景猜了一个并不存在的物体。

SAM 的特点是“给它一个还不错的提示，它能把边界切得很细”。这也意味着 SAM 不会自动纠正上游语义错误。若提示错了，输出可能只是“高质量的错误分割”。

## 3. 摘要逐层解释

### 3.1 论文直接提出的矛盾

现有零样本 COS 方法常把 MLLM 当作目标发现器，再把它的视觉提示传给 SAM。伪装目标的低对比度和多实例场景会让 MLLM 的提示不稳定，出现误报和漏报。

### 3.2 作者的解决方式

DSS 提出渐进式 Discover-Segment-Select 机制：

- FOD 不依赖 MLLM 的一句话判断，而是从视觉特征中找出多个候选目标；
- 分割模块对每个候选生成更精细的 SAM mask；
- SMS 让 MLLM 比较这些候选，选择语义上最合理的 mask。

### 3.3 论文宣称的结果

论文称 DSS 不需要额外训练或监督，在多个 COS 基准上取得有竞争力的零样本结果，尤其在包含多个伪装目标的场景中收益明显。这里的重点是“多候选 + 选择”对多实例更有帮助，而不是单张图只存在一个目标时一定大幅领先。

## 4. 方法详解

### 4.1 总体输入输出

- **输入**：一张自然图像；
- **中间输入**：冻结视觉编码器特征、候选点/框/区域提示、SAM 生成的候选 mask；
- **输出**：一个或多个伪装目标分割 mask。

流程可以写成：

$$
I \rightarrow F \xrightarrow{\text{FOD}} P_1,\ldots,P_K \xrightarrow{\text{SAM}} M_1,\ldots,M_K \xrightarrow{\text{SMS}} M^*.
$$

其中 $I$ 是图像，$F$ 是视觉特征，$P_k$ 是第 $k$ 个候选提示，$M_k$ 是对应 mask，$M^*$ 是最终选择结果。这个公式不是训练目标，而是把论文的推理链条说清楚：**候选提示先增加覆盖，SAM 负责边界，SMS 负责最后的语义筛选。**

### 4.2 FOD：Feature-coherent Object Discovery

#### 输入

FOD 接收冻结视觉编码器输出的多尺度特征。相比直接问 MLLM“目标在哪里”，视觉特征保留了更细的空间结构和局部相似性。

#### 内部操作

FOD 在特征图中寻找具有对象一致性的区域，并生成多个互补候选。所谓 feature-coherent，不是只看某个像素亮不亮，而是看一片区域内部是否具有相对一致的特征，同时与周围背景存在可分的变化。

候选数量不能太少。只输出一个候选时，系统又退化成“一次猜测”；保留多个候选后，目标的不同部分、不同实例以及若干背景误报都可以进入下一阶段。

#### 输出和解决的失败

输出是多个点、框或区域提示。它主要解决 MLLM 单点发现带来的漏检与定位漂移。FOD 并不保证每个候选都是真目标，它的职责更像“扩大召回，把可能性保留下来”。

#### 与下一模块连接

每个候选被送入 SAM。这样上游的粗粒度不确定性不会直接变成最终 mask，而是被转换成多个可比较的分割假设。

### 4.3 SAM 分割：把候选变成边界

SAM 根据点、框或粗区域提示生成一个或多个候选 mask。它的优势是强大的通用边界先验，不需要为 COD 重新训练；它的弱点是对提示依赖很强。

DSS 的关键不是“调用 SAM”本身，而是对 FOD 产生的多种候选分别调用 SAM，并保留候选 mask。这样，SAM 的角色从“最终裁判”变成“候选边界生成器”。

每个 mask 都带有一个置信度或质量信号，但单靠 SAM 的 mask score 不够，因为 SAM 只知道“这个区域像一个物体”，不知道它是不是题目中的伪装目标。这个缺口交给 SMS。

### 4.4 SMS：Semantic-driven Mask Selection

#### 输入

SMS 接收原图、候选 mask 以及候选对应的视觉提示。它把这些候选组织成 MLLM 可以比较的输入。

#### 内部操作

MLLM 不再负责从整张图零起点发现目标，而是回答更窄的问题：**这些候选里哪一个最符合图像中真实、完整、具有物体语义的区域？**

它可以利用目标是否完整、是否包含明显背景、多个候选是否重复、候选是否与场景语义冲突等信息。换句话说，SMS 把 MLLM 从“定位器”改成“选择器”，降低了它一次完成所有空间推理的负担。

#### 输出和解决的失败

SMS 选出最佳 mask，或在多实例场景中合并合理候选。它主要减少 FOD/SAM 阶段产生的背景误报和重复候选。

#### 可能的误差传播

SMS 只能在候选集合中选择。如果 FOD 彻底漏掉目标，后面没有候选可选；如果所有候选都来自背景，MLLM 可能在错误候选中选一个“最像物体”的区域。因此 DSS 是“提高候选覆盖后再筛选”，不是从理论上消除漏检。

## 5. 主要贡献

1. **把零样本 COD 从两阶段变成三阶段渐进过程**：先发现多个候选，再分割，再语义选择，避免让 MLLM 一次承担定位、实例区分和语义判断。
2. **提出 FOD 作为视觉特征驱动的候选生成器**：用特征一致性补充 MLLM 的语义偏差，重点改善漏检和定位漂移。
3. **提出 SMS 作为候选 mask 选择器**：让 MLLM 比较已生成的 mask，而不是直接从整图猜一个提示。
4. **无需针对 COS 训练**：方法主要组合现成视觉基础模型，降低在新伪装类别上适配的成本。
5. **对多实例场景更有针对性**：多个候选让系统有机会同时覆盖多个目标，而不是默认一图一目标。

## 6. 实验怎么看

### 6.1 看什么指标

零样本 COD 通常报告 S-measure、E-measure、F-measure 和 MAE。S/E/F 越高越好，MAE 越低越好。它们从结构相似性、像素级对齐和区域/边界质量等角度评价 mask。

但这些指标只说明预测 mask 与人工标注的相似程度，不直接说明模型是否能在视频中稳定追踪、是否能识别所有未知物体，也不说明 MLLM 和 SAM 的 API 成本是否适合边缘端。

### 6.2 论文结果支持什么

论文在多个 COS 基准上比较已有零样本方法，并报告 DSS 在多实例场景中尤其有效。这个结果与方法逻辑是一致的：多候选机制最直接解决“只找到一个目标”或“把多个目标混成一块”的问题。

消融实验的关键应看三件事：

- 去掉 FOD 后，候选覆盖和召回是否下降；
- 去掉 SMS 后，背景误报和错误候选是否上升；
- 候选数量变化时，性能是否先提升后饱和，过多候选是否带来 MLLM 选择噪声。

### 6.3 不能过度解读的地方

第一，零样本结果好不等于它能替代在目标域训练的 COD 模型。通用模型可能在自然图像上有强先验，但在水下、红外、低照度或工业伪装中会遇到明显域偏移。

第二，MLLM 的选择能力可能依赖提示词设计和模型版本。若换一个 MLLM，候选排序可能改变；若 API 返回不稳定，结果也可能波动。

第三，多阶段推理的计算成本高。即使每个模块都冻结，FOD、多个 SAM 调用和 SMS 的 MLLM 调用仍可能比一个训练好的单模型慢很多。

## 7. 论文缺陷与证据边界

1. **上游漏检无法由 SMS 修复**：选择器只能在已有候选中选，完全漏掉的目标不会凭空出现。
2. **候选数量与成本存在冲突**：候选越多，理论召回越高，但 SAM 调用次数和 MLLM 输入长度也越大。论文若只报告精度而不报告候选数、延迟和调用成本，部署价值仍不完整。
3. **MLLM 仍可能有语义偏见**：选择器可能偏好形状更像常见动物或物体的区域，把真正的伪装目标排掉。
4. **零样本基准不等于真实开放世界**：COD 数据集通常已有明确目标类别和干净标注，真实场景可能包含多个合理前景、透明目标和严重遮挡。
5. **SAM 的边界先验可能掩盖提示错误**：mask 看起来很规整并不代表目标定位正确，应该报告候选覆盖率和实例级漏检，而不只是最终平均分。
6. **跨模态模块的可重复性有风险**：MLLM 的系统提示、温度、版本和图像编码方式都会影响 SMS，若论文没有完全固定这些细节，复现实验会有不确定性。

## 8. 可执行的借鉴与改进

### 8.1 对 COD

可以直接借鉴“候选保留 + 后验选择”，但建议把 MLLM 选择改成更稳定的可学习排序器或能量函数，并保留 MLLM 作为离线教师。控制实验：固定 FOD 和 SAM，只比较 SAM score、轻量排序器和 MLLM SMS 三种选择方式，报告 S-measure、目标漏检率、每张图推理时间。

### 8.2 对 UAV

UAV 小目标也常出现“多个候选都像目标”的问题。可以让高分辨率特征产生候选，再用检测器/分割器重排。但候选生成必须保留小目标，不应直接使用低分辨率全局特征。最小实验按目标面积分组报告 APsmall/召回率，同时记录每张图候选数和端侧延迟。

### 8.3 对烟雾分割

烟雾不像实体目标，SAM 的封闭边界先验可能把半透明烟团切得过于规整。因此更合理的迁移是：FOD 生成“疑似烟区候选”，分割模块产生不同浓度/边界假设，SMS 或轻量排序器根据天空、植被、风向和时间连续性选结果。

最小控制实验为：RGB 单模型、候选式 RGB、候选式 RGB+时间三组；指标包括早期烟雾召回、云雾蒸汽误报率、边界 F1、首次报警时间和每小时误报次数。如果候选式方法只提高召回却显著增加误报，就不能直接用于预警。

## 9. 精读结论

DSS 的核心价值是把“零样本模型一次猜答案”改成“保留多个解释，再逐步淘汰错误解释”。对 COD，它提供了一个清楚的工程原则：**发现阶段优先提高候选覆盖，分割阶段专注边界，最后再做语义和完整性判断。**

它不是低成本实时方案，也没有解决上游完全漏检、跨域传感器差异和 MLLM 不稳定的问题。但作为 COD 研究的结构参考，DSS 比单纯增加一个注意力模块更值得精读，因为它直接针对了伪装目标任务中最容易被忽略的误差传播链条。
