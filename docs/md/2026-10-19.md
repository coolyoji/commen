### S2C-3D：Sparse-to-Complete: From Sparse Image Captures to Complete 3D Scenes

- **作者**：Yiyang Shen, Yin Yang, Kun Zhou, Tianjia Shao
- **原始出处**：SIGGRAPH Conference Papers 2026；DOI `10.1145/3799902.3811099`
- **预印本月份**：2026 年 5 月；会议出处月份：2026 年 7 月
- **论文**：<https://arxiv.org/abs/2605.05664>
- **项目/代码/数据**：<https://gapszju.github.io/S2C-3D>
- **Zotero**：`每日精读论文/2026/10`；顶层条目 `T3MJDPEW`；附件 `YQ8D4Z8A`
- **精读长文**：[s2c-3d.md](longform/2026-10/s2c-3d.md)

### 先说人话

S2C-3D 处理“只有 6--8 张照片，但想得到完整室内三维场景”的问题。它不是把每张图单独修清楚再拼起来，而是把三个环节连起来：先用当前场景微调扩散模型，再规划真正能看到新区域的虚拟相机，最后用跨视角重投影一致性约束扩散采样和 3D Gaussian 优化。这样可以减少大面积缺失、跨视角模糊和重复表面。

### 摘要和方法拆解

1. 用 `π3` 从稀疏未标定图像估计相机姿态、点云，并初始化低质量 3D Gaussian；
2. 对预训练扩散模型做场景专用 LoRA 微调，训练对由输入图像和人为退化/遮挡图像构成；
3. 用信息增益规划相机轨迹，使虚拟相机覆盖输入视角未覆盖的区域；
4. 用深度和姿态建立相邻视角对应，计算一致性能量，并将其作为扩散采样的条件梯度；
5. 反复用修复图像优化 Gaussian，得到完整场景。

### 关键术语详细解释

- **域差异（domain gap）**：通用扩散模型熟悉的是训练数据分布，而当前房间有自己的材质、灯光和布局。直接套用会生成“像一个房间但不是这个房间”的纹理。场景专用微调用当前可见视图把模型拉回目标场景分布。
- **信息增益（information gain）**：不是图像清晰度，而是一个新相机相对已有相机多看到多少局部区域。它回答“下一步去哪里拍最有用”。
- **跨视角一致性条件**：将相邻视角的深度和颜色反投影到当前视角，若对应像素冲突，就在扩散采样时施加修正梯度。这样生成结果不能只在单张图上好看，还要能和邻居拼成同一个 3D 场景。
- **3D Gaussian Splatting**：用带位置、尺度、旋转和颜色的三维 Gaussian 表示场景，优化快，但稀疏输入下容易出现洞、重复表面和漂浮伪影。

### 实验和证据

论文在 ScanNet++、Replica 和作者自采的 S2C-Scene 上测试 4/5/6 或 6/7/8 个视图。完整模型在 ScanNet++ 的 6/7/8 视图上 PSNR 为 17.779/17.990/18.777，SSIM 为 0.683/0.690/0.706，LPIPS 为 0.344/0.333/0.315。Replica 6 视图上 PSNR 为 20.360、SSIM 为 0.721、LPIPS 为 0.281。消融显示去掉遮挡 mask 微调、轨迹规划或一致性条件都会明显下降。

### 贡献

**论文原文事实：**

1. 提出面向 6--8 张输入图像的稀疏到完整场景重建框架；
2. 提出场景专用扩散修复；
3. 提出覆盖增益驱动的相机轨迹规划；
4. 提出免训练的跨视角一致性条件采样。

**基于证据的解释：** 真正的贡献不是某个单独模块，而是把“适应当前场景、获得新观察、消除视角冲突”变成一个闭环。

### 缺陷和证据边界

- 论文主要验证室内、静态、输入视锥内的场景；
- 凹形房间可能在墙体外生成错误区域；
- 贪心轨迹规划不保证全局最优，随机候选相机可能落到物体内部；
- 扩散修复得到的是合理补全，不是不可见区域的唯一真值；
- PSNR/SSIM/LPIPS 不能证明隐藏表面的语义或拓扑一定正确；
- 没有验证动态视频、UAV 大范围户外、天气变化和强域偏移。

### 对 amodal 补全、三维重建和三维 amodal 补全的迁移

- **amodal 补全**：把可见 mask、遮挡顺序和重投影误差作为生成条件，不把隐藏部分当成普通像素修补。
- **三维重建**：可复用“场景适配 + 新视角规划 + 跨视角一致性”的闭环。
- **三维 amodal 补全**：应显式输出 visible/inferred/unknown 三类证据和不确定性，而不是只输出一个完整点云。
- **UAV/开放场景**：将覆盖增益改成不确定性下降，并加入不可飞区域、地面/天空边界、动态物体和在线增量更新。

### ARIS 结果

1. **真正问题与缺口**：稀疏视角方法在大面积未知区域出现域差异、虚拟相机覆盖不足和多视角冲突；现有方法通常只解决其中一个。
2. **为什么需要该方法**：后处理补洞无法保证不同视角产生同一个表面，因此需要在场景适配、观测规划和一致性优化三层同时处理。
3. **为什么可能有效**：场景微调减少生成域偏移；信息增益提供新证据；重投影能量把生成结果拉回几何一致性。
4. **依赖和失败**：依赖粗相机/点云、可靠深度和静态场景；错误深度、凹形空间、动态物体会把错误一致地传播。
5. **作者贡献与证据**：表 1 支持多数据集性能提升，表 2 支持三个关键组件的必要性，讨论部分明确承认开放场景和凹形房间限制。
6. **尚未解决**：没有可见/不可见分解、多假设输出、显式不确定性和动态对象记忆。
7. **研究 idea**：
   - **Evidence-Decomposed S2C**：将 Gaussian 分成 observed/inferred/uncertain，最小实验比较隐藏区域 CD 和置信度校准，风险是增加容量但不增加真正可解释性。
   - **Uncertainty-Guided UAV Active Completion**：用多假设补全的熵下降选下一视角，比较随机、最大覆盖和不确定性引导，风险是不确定性可能只是生成噪声。
   - **Dynamic Object Tokens**：静态背景和动态对象分别维护 temporal memory，比较逐帧、全局时间 token 和对象 token 的 3D jitter，风险是跟踪错误污染记忆。

### 1. Amodal3R：Amodal 3D Reconstruction from Occluded 2D Images

- **出处**：arXiv:2503.13439，2025 年 3 月；项目页 <https://sm0kywu.github.io/Amodal3R/>
- **先说人话**：它直接从被遮挡的二维图像恢复完整三维物体，避免“先做 2D amodal 补全，再把错误几何传给 3D”的级联。
- **摘要拆解**：以 foundation 3D generative model 为起点；使用 mask-weighted multi-head cross-attention 和 occlusion-aware attention；只用合成数据训练，测试真实遮挡场景；对比独立 2D 补全再 3D 重建的流程。
- **方法为什么可能有效**：mask 权重让模型知道哪些像素是可靠可见证据；occlusion-aware attention 将遮挡先验注入 3D latent；直接在 3D 空间生成，减少 2D 边界误差被放大。
- **贡献**：把对象级 amodal 3D 作为直接目标，并提供遮挡场景基准。**证据边界**：主要是对象级，不能直接推出杂乱开放场景和视频有效。
- **缺陷**：依赖对象级 crop 和形状先验；长尾类别、非刚体、强反光和错误 mask 会造成模板化幻觉。
- **迁移**：可将 visible/occluder/depth-order 作为三维补全条件；对 UAV 场景需要再加多视角和地面尺度约束。
- **ARIS 诊断**：
  1. **问题/缺口**：现有方法只重建可见表面或把 2D 补全误差级联到 3D；
  2. **为什么需要**：隐藏结构是 3D 目标的一部分，不能只优化可见像素；
  3. **为什么有效**：对象 latent 汇聚形状先验，遮挡 attention 把可见性作为条件；
  4. **依赖/失败**：依赖对象边界、类别先验和合成到真实的迁移；
  5. **贡献/证据**：摘要明确写出直接 3D 生成、mask attention 和合成训练；
  6. **未解决**：场景级、多视角、动态和未知类别泛化；
  7. **Ideas**：
     - `Occluder-aware latent`：加入遮挡物深度顺序；实验按遮挡率比较 hidden-surface CD；风险是深度顺序在真实数据中难获取。
     - `Category-agnostic structural tokens`：分离类别语义和几何结构；实验留出类别测试；风险是丢失有用先验。
     - `Multi-view amodal fusion`：各视角生成候选再用跨视角一致性融合；实验比较 1/2/4 视角；风险是视角关联错误。

### 2. GENA3D：Generative Amodal 3D Modeling by Bridging 2D Priors and 3D Coherence

- **出处**：arXiv:2511.21945，2025 年 11 月；ECCV 2026 接收；项目页 <https://colezwhy.github.io/gena3d/>
- **先说人话**：它试图同时要两件事：2D 生成模型擅长的“根据局部线索想象外观”，以及 3D 表示需要的“几何结构和多视角一致”。单独用 2D 先验会出现几何不一致，单独用 3D 生成又可能缺少生成表达力。
- **摘要拆解**：将 learned 2D generative priors 与显式 3D reasoning 结合；用 View-Wise Cross-Attention 做多视角对齐；用 Stereo-Conditioned Cross-Attention 注入 3D 关系；输出完整、连贯物体。
- **术语解释**：`View-Wise Cross-Attention` 是按视角组织的跨注意力，让不同观察不互相平均；`Stereo-Conditioned` 用左右/多视角几何关系约束生成，而不是只看外观相似。
- **贡献和证据**：作者声称在 synthetic 和 real-world amodal 场景中优于现有方法。公开摘要支持方法结构和总体结论，但今天未下载 PDF，因此不记录未经核验的具体数值。
- **缺陷**：2D 先验可能生成漂亮但错误的隐藏细节；多视角关系依赖相机估计和匹配质量；采样成本与不确定性评估仍需验证。
- **迁移**：适合做三维 amodal 多假设生成；开放场景中应加入物体接触、支撑、遮挡关系，防止独立物体“各自合理、整体不可能”。
- **ARIS 诊断**：
  1. **问题/缺口**：2D 生成先验和 3D 几何一致性之间存在断层；
  2. **为什么需要**：amodal 隐藏区域既需要外观先验，又必须满足空间约束；
  3. **为什么有效**：view-wise attention 对齐观察，stereo attention 提供跨视角几何信号；
  4. **依赖/失败**：依赖多视角关系、可靠匹配和 2D 先验质量；
  5. **贡献/证据**：摘要明确报告 2D prior + 3D coherence 的框架和 synthetic/real-world 验证；
  6. **未解决**：多解校准、开放类别、动态物体和场景关系；
  7. **Ideas**：
     - `Evidence-ranked sampling`：用重投影、深度顺序和接触关系给生成候选排序；最小实验比较随机与证据排序；风险是过度偏好保守形状。
     - `Uncertainty calibration`：把多样性与隐藏区域误差关联；实验按遮挡率评估 ECE；风险是采样方差混入模型噪声。
     - `Scene-graph constrained generation`：用支撑/接触/遮挡关系过滤候选；实验统计物理违反率；风险是关系标注贵。

### 3. TACO：Taming Diffusion for in-the-wild Video Amodal Completion

- **出处**：arXiv:2503.12049，2025 年 3 月；ICCV 2025 接收；项目页 <https://jason-aplp.github.io/TACO>
- **先说人话**：TACO 不是只补一帧，而是让视频里同一个被遮挡物体在连续帧中保持完整外观和形状一致。它利用预训练视频扩散模型的时间流形，并用渐进式难度训练适应真实网络视频。
- **摘要拆解**：构建多难度合成遮挡视频数据；从简单恢复任务逐渐训练到复杂遮挡；覆盖互联网视频、自动驾驶、机器人操作和场景理解；还验证物体重建和姿态估计下游任务。
- **关键术语**：`Video Amodal Completion` 要求恢复视频中物体不可见部分；`progressive fine-tuning` 先学容易的遮挡，再逐步增加难度，减少模型一开始被强遮挡伪目标带偏。
- **贡献和证据**：公开摘要支持视频扩散、渐进式训练、多场景测试和下游应用；具体指标不在今日泛读中展开。
- **缺陷**：时间一致性可能传播第一帧的错误；长时间完全遮挡时没有新证据；网络视频的相机运动、光照和目标出入画面会破坏假设。
- **迁移**：对三维 amodal 可把视频完成结果作为 2D evidence，但必须用 3D 重投影筛掉时间上稳定却几何错误的结果。
- **ARIS 诊断**：
  1. **问题/缺口**：单帧补全会闪烁，视频中的遮挡物体无法稳定恢复；
  2. **为什么需要**：相邻帧提供重复观测，可以约束隐藏区域变化；
  3. **为什么有效**：视频扩散 latent 保留时间结构，渐进训练缓解强遮挡难度；
  4. **依赖/失败**：依赖帧间对应、运动估计和合理伪目标；
  5. **贡献/证据**：摘要列出合成数据、渐进微调和多个真实域验证；
  6. **未解决**：时间稳定不等于三维正确，长遮挡和动态非刚体仍难；
  7. **Ideas**：
     - `2D-3D bidirectional consistency`：同时约束 mask track 和 3D shape track；实验比较 2D-only/3D-only/joint；风险是错误 3D 反过来污染 2D。
     - `Occlusion-event segmentation`：区分短遮挡、长遮挡和重新出现；实验按事件时长报告性能；风险是事件标签噪声。
     - `Memory reset detector`：用可见区域重投影误差检测何时丢弃旧记忆；实验注入跟踪失败；风险是重置过频。

### 4. Occlusion-Aware Temporally Consistent Amodal Completion for 3D Human-Object Interaction Reconstruction

- **出处**：arXiv:2507.08137，2025 年 7 月；ACM MM 2025；DOI `10.1145/3746027.3754769`
- **先说人话**：这篇针对的是视频中的人和物体互相遮挡。普通三维重建往往假设物体静止或完全可见，遇到人挡住物体、手挡住工具时就会出现结构缺失和时间跳变。
- **摘要拆解**：从单目视频恢复动态人-物交互；用 amodal completion 推断被遮挡结构；把时间上下文加入增量重建；使用 3D Gaussian Splatting 验证遮挡处理和时间稳定性。
- **关键术语**：`template-free` 表示不依赖固定人体/物体模板；`incremental refinement` 表示随视频帧到来逐步更新，而不是每帧独立重建。
- **贡献和证据**：摘要明确声称在遮挡和时间稳定性上优于基线。没有 PDF 时不把摘要中的 “superior precision” 解释成具体数值提升。
- **缺陷**：人-物遮挡的对应关系和深度排序容易错；动态非刚体、快速运动、重新出现和视角抖动会导致错误传播。
- **迁移**：可把 object-centric temporal tokens 用于 UAV 中车辆/人员遮挡的三维 amodal 补全；需要增加静态背景和动态实例的分离。
- **ARIS 诊断**：
  1. **问题/缺口**：静态/全可见假设不适用于动态交互；
  2. **为什么需要**：遮挡区域的真实几何和身份必须在时间上连续；
  3. **为什么有效**：时间上下文提供额外证据，amodal 输出为后续 3DGS 提供完整目标；
  4. **依赖/失败**：依赖稳定跟踪、深度排序和运动模型；
  5. **贡献/证据**：摘要支持 template-free、时间上下文和 3DGS 验证；
  6. **未解决**：开放世界类别、跨摄像机视角和不确定性输出；
  7. **Ideas**：
     - `Object-centric temporal memory`：背景和实例分开记忆；实验比较 3D jitter 和身份漂移；风险是跟踪错误路由。
     - `Visibility-state transition model`：显式建模 visible/occluded/reappeared 状态；实验按状态转移评估；风险是状态标注难。
     - `Contact-aware completion`：加入手-物体接触和支撑约束；实验统计接触几何违反率；风险是接触估计误差。

### 5. DeOcc-1-to-3：3D De-Occlusion from a Single Image via Self-Supervised Multi-View Diffusion

- **出处**：arXiv:2506.21544v2，2025 年 6 月；项目页 <https://quyans.github.io/DeOcc123/>
- **先说人话**：只给一张被遮挡的物体图像，DeOcc-1-to-3 先生成 6 个结构一致的新视角，再用这些视角做三维重建。它不先把原图硬 inpaint，而是让多视角生成过程共同承担“去遮挡”和“补几何”。
- **摘要拆解**：针对真实遮挡下的单图三维重建；用遮挡/无遮挡图像对和伪真值视角进行自监督训练；完全微调视图生成模型；提出覆盖不同遮挡率、类别和 mask 模式的 benchmark。
- **关键术语**：`self-supervised multi-view diffusion` 用合成遮挡生成训练对，不需要人工标注每个隐藏面；`structurally consistent views` 要求生成的多个视角来自同一个物体，而不是六张独立的漂亮图片。
- **贡献和证据**：摘要支持端到端框架、自监督数据构造、六视角生成和 benchmark。今天未下载 PDF，具体提升数值不写。
- **缺陷**：单图隐藏结构仍然多解；生成视角之间看似一致但可能共享错误先验；细长结构、非对称物体和未知类别容易失败。
- **迁移**：适合给三维 amodal 补全增加多假设视角证据；开放场景中应加入场景坐标、物体关系和跨视角深度检查。
- **ARIS 诊断**：
  1. **问题/缺口**：单图遮挡使传统多视图生成器失去完整输入；
  2. **为什么需要**：多视角生成能把一个二维观察转换成多个几何约束；
  3. **为什么有效**：遮挡/无遮挡对教模型从局部证据预测结构，多视角一致性抑制独立幻觉；
  4. **依赖/失败**：依赖合成遮挡与真实遮挡相似、生成视角足够多样且一致；
  5. **贡献/证据**：摘要明确给出六视角、self-supervision 和新 benchmark；
  6. **未解决**：不确定性校准、真实长尾和场景级多物体；
  7. **Ideas**：
     - `Geometry-ranked view set`：按深度/重投影一致性挑选生成视角；实验比较随机六视角与排序子集；风险是排序偏好过度平滑。
     - `Multi-hypothesis 1-to-3`：保留多组视角集合而非一组；实验报告 best-of-N 和 coverage；风险是计算成本增加。
     - `Open-world relation conditioning`：加入支撑、接触和遮挡关系；实验在杂乱场景中测关系违反率；风险是关系识别误差。

## 跨论文 ARIS 归纳

### 共同问题

1. 隐藏区域往往被当作确定性输出，缺少 observed/inferred/unknown 区分；
2. 2D 生成先验很强，但与 3D 几何、跨视角和物体关系的约束还不够显式；
3. 视频时间一致性可能把错误稳定化，单帧质量提升不等于三维正确；
4. 视角规划通常优化覆盖面积，没有直接优化隐藏结构不确定性；
5. 大多数实验仍集中在对象级或室内静态数据，开放场景、UAV、动态物体和域偏移证据不足。

### 最值得先做的研究方向

**Evidence-Decomposed 3D Amodal Completion**：每个三维 primitive 同时预测几何、证据来源和不确定性；可见区域使用强重投影约束，隐藏区域用多假设和校准评价。

**Uncertainty-Guided Active Reconstruction**：先生成多个三维补全候选，再让 UAV 选择能最大减少隐藏区域不确定性的下一视角。

**Dynamic Object-Centric Amodal Memory**：静态背景使用全局场景记忆，动态物体使用实例级时间记忆，并用可见重投影误差触发回退。

## 今日结论

今天的文献共同说明：三维 amodal 补全的关键不是单纯扩大生成模型，而是把**可见证据、生成先验、跨视角几何、时间状态和主动观测**分开建模，再用一致性把它们接起来。S2C-3D 提供了完整场景闭环；Amodal3R 提供直接对象级 3D 补全；GENA3D 和 DeOcc-1-to-3 提供 2D 生成先验与多视角一致性；TACO 和 ACM MM 论文提醒我们视频时间稳定既是证据也是风险。所有 ARIS idea 都是可验证假设，不是论文已证明的结论。
