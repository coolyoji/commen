# Preference-Guided Adaptation for Open-Vocabulary Semantic Segmentation via Prompt Disagreement

## 先说人话

这篇文章解决的是一个很现实的问题：开放词汇分割模型到了遥感、医学、工业检测等陌生领域后会变差，但重新为每个像素画 mask 太贵。作者没有要求标注员重新画完整真值，而是让标注员在一个小区域里回答一个简单问题：

> 两个候选分割，哪个更接近我想要的结果？

这两个候选不是额外训练出来的，而是同一个模型换几种 prompt 模板后自然产生的两个结果。作者把这种“同一张图换一句提示词就得到不同 mask”的现象叫 **prompt disagreement**，再把它变成适配监督。

关键不在于“让人少点几下”，而在于把一次局部二选一转成像素级更新：选出来的优胜 mask 在局部区域被增强，落选 mask 被压低；区域外再用一致性约束，避免模型为了修好一个小区域而把整张图改坏。

## 摘要拆解

1. **问题**：OVSS 依赖自然图像预训练，遇到遥感、医学、工业等域偏移时，类别词和视觉特征都可能失配。
2. **监督替代**：用二元偏好替代密集像素 mask。标注员只需要在局部区域比较两个候选。
3. **候选来源**：不同 prompt 模板产生不同预测，模板差异本身就是候选生成器。
4. **查询定位**：用跨模板熵找最不稳定区域，再选在该区域分歧最大的模板对。
5. **优化方法**：提出 Region-Localized Preference Optimization（RLPO），把 DPO 的偏好学习改造成区域级分割分数比较。
6. **稳定机制**：在被询问区域之外，用优胜预测作为伪目标约束落选分支，减少无关区域漂移。
7. **结果**：MESS 五大领域、四个 OVSS backbone 上都获得提升，并且在偏好标签有噪声时仍然有效。

## 方法流程

### 1. 先制造多个候选

给定一张目标域图片和类别词表，使用 14 个 ViLD prompt 模板，例如：

```text
a photo of a [Class]
This is a photo of a [Class]
There is the [Class] in the scene
```

模型得到 14 张候选分割。这里的候选不是不同模型，而是同一模型、同一类别、不同语言模板的输出。

### 2. 找真正值得询问的区域

对每个像素，把 14 个模板的类别分布求平均，再计算熵：

```text
平均分布越分散，熵越高，说明不同模板越不一致。
```

作者取熵的 95% 分位数，把高熵像素连成区域，并取最大连通区域的外接框作为查询区域 `R`。这样不要求人比较整张大图，而是只看模型最犹豫的地方。

然后在 `R` 内逐对统计模板硬标签不同的像素数，选择分歧最大的模板对 `(a, b)`。这一步的作用是保证二选一不是“两个几乎一样的结果”，而是确实存在可辨别差异。

### 3. 用 RLPO 把二选一变成训练信号

标注员或 oracle 判断 `a`、`b` 谁更好，得到 winner 和 loser。作者没有直接对整个图求平均概率，因为大面积背景会淹没小目标，于是做了 **class-balanced regional score**：

1. 按 winner 的预测类别把 `R` 划成若干类；
2. 每个类内部先平均像素对数概率；
3. 再对出现的类别平均。

这样，小面积但关键的类别不会被大面积背景完全盖住。

RLPO 的形式是 Bradley-Terry / DPO 风格的对数 sigmoid：

```text
让 winner 相对参考模型的区域分数高于 loser，
同时保留 reference model 作为 KL 锚点，避免更新幅度失控。
```

实际训练只更新轻量模块：视觉分支 rank-4 LoRA 和文本分支 residual prompt embedding，主干保持冻结。每张流式到来的图片执行一次更新，不回看旧图，不做大批量离线训练。

### 4. 为什么还需要一致性正则

RLPO 只在 `R` 内有偏好监督。如果不加限制，模型可能为了提高 `R` 内 winner 分数，顺手改变 `R` 外完全无关的区域，表现为：

- 原来正确的区域被改错；
- loser 分支在未询问位置发生漂移；
- 模型对同一 prompt 的输出变得不稳定。

作者因此在 `R` 外挑选 winner 置信度足够高的像素，把 winner 的硬预测当成伪标签，对 loser 分支加 Lovász-Softmax 一致性损失。它不是说 winner 一定是真值，而是说：**既然当前没有人要求你改这些地方，就不要无缘无故改动它们。**

## 关键术语详细解释

### Prompt disagreement

这里不是“模型随机抖动”，而是同一个类别词换不同句式后，文本 embedding 与视觉特征的相对相似度发生变化，最终导致不同像素的类别排序改变。域偏移时这种现象更严重，因为模型没有学到目标域中“什么样的视觉模式对应这个词”，语言模板的细小偏差会被放大。

失败原因有三层：

1. **文本先验失配**：自然图像中常见的 “a photo of” 与遥感、医学图像的语体不匹配；
2. **像素特征边界弱**：小目标或低对比目标的视觉分数本来就接近；
3. **类别竞争敏感**：当两个类别的相似度很接近时，模板改变会改变 winner。

因此，prompt disagreement 既是噪声，也是可利用的“不确定性传感器”。

### Region-Localized Preference Optimization（RLPO）

它本质上是把 DPO 的“整条回答谁更好”改造成“这块区域里哪张分割更好”。区域化有两个重要作用：

- 降低标注难度：人能看懂局部二选一，整图比较往往会被不同区域的优劣抵消；
- 提高梯度密度：一次二选一可以约束区域内很多像素，而不是只产生一个粗粒度图像标签。

### DPO / Bradley-Terry

DPO 不先训练一个奖励模型，而是直接让模型提高 winner 的相对概率、降低 loser 的相对概率。Bradley-Terry 假设两个候选被偏好的概率取决于它们的分数差。这里的“分数”不是语言模型生成句子的概率，而是模板条件下、区域内分割结果的 class-balanced log-likelihood。

### Consistency regularization

一致性正则不是额外的真值监督，而是“未被询问的地方不要乱动”的约束。它解决的是局部优化的副作用：偏好损失集中在一个小区域，模型参数却会影响整张图，所以必须用参考预测把无关区域拴住。

### 偏好噪声为什么仍然能工作

一次错误偏好只会把一个局部 winner/loser 方向推反，而且参考模型和后续多次样本会提供反向约束。只要错误不是系统性偏向同一个类别，累积平均后仍可能保留正确趋势。论文在 CAT-Seg-L 上把偏好翻转概率提高到 20%，平均仍保留约 8 mIoU 的提升，但这不代表人工标注可以随便错。

## 主要贡献

1. **把 prompt 差异变成监督信号**：不再把不同模板的输出差异只当作 nuisance，而是用作候选偏好来源。
2. **提出局部偏好查询挖掘**：同时解决“问哪里”和“比较哪两个候选”。
3. **提出 RLPO**：把 DPO/偏好优化具体化到像素分割区域，并用 class-balanced score 防止背景主导。
4. **提出区域外一致性约束**：降低局部适配导致的全图漂移。
5. **低成本适配**：仅需二选一偏好和轻量 LoRA/prompt adapter，不需要密集 mask。

## 实验结果

实验在 MESS 的五个领域组上进行：General、Earth Monitoring、Medical Sciences、Engineering、Agriculture & Biology。四个 backbone 的整体结果如下：

| Backbone | Zero-shot | +Ours | 平均提升 |
|---|---:|---:|---:|
| SAN-B | 25.29 | 32.39 | +7.10 |
| CAT-Seg-B | 33.12 | 39.67 | +6.55 |
| SAN-L | 27.40 | 33.99 | +6.59 |
| CAT-Seg-L | 35.26 | 45.88 | +10.62 |

几个结果比总平均更值得记住：

- Medical Sciences 是提升最大的领域，SAN-B 上约 +19.46，CAT-Seg-L 上约 +22.31；
- 只用 4 张适配图，平均已经提升约 3 mIoU；16 张约 +7.05；64 张约 +10.62；
- 128 张为 +10.53，和 64 张几乎持平，说明收益在 64 张左右趋于饱和；
- 候选生成对比中，prompt disagreement 的平均 mIoU 为 45.88，高于 MC Dropout 的 39.09 和 TTA 的 44.66；
- 去掉 RLPO 后平均降到 40.51，去掉一致性正则后为 43.45，说明 RLPO 是主驱动，一致性负责稳定；
- 偏好标签翻转 20% 时，仍保留约 8 mIoU 的平均收益。

这组实验支持的不是“二选一一定替代 mask”，而是：在固定适配预算下，局部相对判断可以成为有用的弱监督，尤其适合密集标注昂贵的专业域。

## 论文缺陷与证据边界

1. **候选上限决定方法上限**：如果所有 prompt 都错，oracle 只能选“相对不差”的结果，无法凭空产生正确 mask。
2. **依赖自然语言可表达性**：高度专业、细粒度或本地化类别如果无法被 prompt 表达，偏好信号仍然弱。
3. **oracle 不是完整人工实验**：论文用真实 mask 计算区域 IoU 来模拟人工偏好，并在附录验证其合理性，但真实标注员的时间、分歧和疲劳成本还没有被充分测量。
4. **并非完全无参数适配**：主干冻结，但仍需要视觉 LoRA 和文本 prompt adapter；部署时要维护适配状态和优化器。
5. **单步流式假设较强**：每张图只更新一次、不回放旧样本，遇到连续错误偏好或长时间域变化时，可能出现灾难性漂移。
6. **MESS 不是烟雾时序基准**：实验覆盖遥感、医学、工程等专业域，却没有验证扩散、分裂、遮挡和快速变化的烟雾视频。
7. **提示模板池固定**：14 个 ViLD 模板适合实验比较，但不保证适合中文、热红外、低照度或消防专业词汇。

## 对 COD、UAV、烟雾分割的迁移

### COD

COD 中的难点通常不是“有没有目标词”，而是目标和背景纹理太像。可以让多个 prompt 或多个描述词产生候选 mask，再在边界不确定区域做二选一。最值得迁移的是 class-balanced regional score，因为伪装目标经常面积小，不能让背景像素把目标信号淹没。

但 COD 的风险也更明显：如果两个候选都把背景纹理当作目标，偏好学习会把错误固化。因此应把候选来源扩展到不同视角、边界增强和局部 crop，而不是只改变句式。

### UAV

UAV 遥感是这篇论文最直接的迁移场景。目标域图像连续到来时，可先用高熵区域找出建筑、道路、车辆、洪水边界等分歧点，再让人只比较局部候选。适配更新可以放在飞行批次之间，或使用轻量 LoRA 在边缘设备上低频更新。

要特别防止航线偏差：同一场景连续帧高度相关，若偏好标注或伪 oracle 只覆盖一种视角，模型可能学到航线特定外观，而不是目标类别本身。

### 烟雾分割

烟雾分割可以借鉴“在最不确定区域提问”，例如烟团边界、烟与云的接触区、半透明层和远距离薄烟。候选可以来自不同 prompt（smoke plume、haze、steam）或不同时间窗口。

但不能直接照搬静态 mask 偏好。烟雾会扩散、分裂、消散，区域外一致性如果过强，可能把旧烟团错误地保持在原地。更合理的版本是：

- 区域内用偏好优化；
- 区域外加入时间衰减和光流一致性；
- 对云、雾、蒸汽设置竞争类别；
- 让“未知/冲突”成为合法状态，而不是强行二选一。

## 精读结论

这篇论文真正的价值是提出一种监督设计：**当完整真值昂贵时，不要只想办法预测一个更好的 mask，也可以设计一个人容易回答、模型能高密度利用的相对判断。** Prompt disagreement 不是模型内部的随机噪声，而是域偏移导致的可观测不稳定性。RLPO 将这个不稳定性转换成局部、可控、带参考锚点的适配信号。

它最适合“候选至少有一个大致正确、人工能快速判断、目标域变化明显”的场景；不适合所有候选都错、目标高度动态、或类别词本身无法表达的任务。对 COD/UAV/烟雾分割，建议优先迁移“高不确定区域查询 + class-balanced 局部偏好 + 区域外保守约束”三件事，而不是直接复制整套损失。
