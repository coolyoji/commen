## Gate3DGen：先判断“该不该动图”，再决定“怎么动图”

原始出处：[arXiv:2610.31649](https://arxiv.org/abs/2610.31649)，首次公开 **2026 年 10 月**；阅读版本 v1，13 页。官方项目、代码和许可证已经核验；PDF 已下载并导入 Zotero `每日精读论文/2026/10`，附件与下载缓存 SHA256 均为 `a4976d...0b39`。

### 1. 先说人话

单图到三维模型的问题常被说成“输入有噪声”。更准确的说法是：三维生成器把照片里的每个视觉线索都当成形状证据，但真实照片里的暗部、运动模糊、反光和遮挡会让这些线索失真。Gate3DGen 加了一个门卫：先判断图像是否需要处理；干净图直接 KEEP，确实受损才 PURIFY。净化器只做一次 flow-matching 前向，并用主体区域、差分退化区域和边缘损失约束它别把物体身份和轮廓一起改掉。

关键边界是：它在合成数据上把“受损输入”拉回同一资产的 clean reference，证明的是输入更适合下游生成器；它没有直接观察真实背面，也没有证明净化后的隐藏表面就是物体真实几何。

### 2. 摘要与引言拆解

【论文原文事实】作者指出现有单图 3D 模型通常假设主体居中、清晰、完整可见、光照均匀；现实照片违反这些前提。方法由 degradation-aware router 和 one-step purifier 组成，冻结下游 3D generator。数据引擎从 3,961 个 3D asset 渲染视图，再合成复合退化，得到约 43,936 对训练图和 1,082 个带 3D ground truth 的测试案例。

【基于证据的解释】真正的缺口不是“缺少一个更强的图像编辑器”，而是普通图像编辑的目标与三维生成目标错位：编辑器只需让二维画面更像，可能为了去阴影而抹掉曲率、为了补遮挡而改变轮廓。Gate3DGen 将下游生成器冻结，因而能把提升归因到输入预处理链，至少在合成评测上隔离了一个变量。

### 3. 方法流程与因果链

1. **输入图像 → router logits → KEEP/PURIFY**。Qwen2.5-VL 路由器输出 `p=σ(o_purify-o_keep)`；阈值化后决定是否干预。路由器不仅输出离散门，还输出给净化器的 degradation-aware features。
2. **受损图像 → observation latent + router features → one-step flow matching → purified image**。在 $t=1$ 处用一次速度预测得到 clean latent 估计，不做多步去噪。
3. **purified image → 冻结的 TRELLIS.2/Pixal3D → 3D mesh/渲染**。下游参数不更新，几何变化来自输入变化。

【深层根因】第一层：下游模型把错误亮度、边界和遮挡当作物体属性。第二层：训练数据中的“图像证据”和真实三维状态之间存在结构性错配；纯像素重建会奖励“看起来像”的修复，而不是“对隐藏几何有帮助”的修复。因此作者加入 region/edge 约束，但这些仍是二维代理。

### 4. 关键术语直白解释

- **Selective routing**：不是所有输入都修。它解决“修复本身会造成破坏”的根因；删除后 clean image 也会被编辑，身份漂移会累积。最易失败场景是 router 把轻微但关键的退化判成 KEEP。
- **One-step flow matching**：把噪声 latent 和 clean latent 之间的路径速度一次估计出来。它解决迭代扩散太慢；删除后需多步采样，部署时间上升。代价是 endpoint 近似可能牺牲细节和多解表达。
- **Region loss**：同时对主体 mask 和观测/参考差分区域加权。它让模型把容量放在物体和真正变化处；但 mask 来自 RMBG-2.0、差分图来自合成 reference，错标会把错误区域变成强监督。
- **Edge loss**：对水平/垂直有限差分加权，保护轮廓和高频梯度。它在表示上约束边界变化，在推理上减少轮廓漂移；删除后图像可能更平滑，几何边界更易错。它无法区分真实薄结构和噪声边缘。

### 5. 公式与优化行为

【原文事实】路由为 $p=\sigma(o_{\rm purify}-o_{\rm keep})$，预处理结果为 $\hat x_c=x_o$（KEEP）或 $C_\theta(x_o)$（PURIFY）。flow matching 用 $z_t=(1-t)z_0+t\epsilon$，在 $t=1$ 时用 $\hat z_0=\epsilon-v_\theta(\epsilon,E(x_o),h,1)$。总损失为 latent、L1、LPIPS、region、edge 的加权和。

【基于证据的解释】冻结生成器意味着优化目标不是“让净化图漂亮”，而是希望它落在下游生成器已学会的输入流形上。但训练并没有对隐藏表面直接反传；mesh distance 只在测试时评价，所以净化器依然可能学到二维捷径。

### 6. 实验：问题→设计→答案

| 问题 | 设计 | 论文给出的答案与边界 |

| 下游 3D 是否改善？ | TRELLIS.2 与 Pixal3D，输入/clean oracle/编辑基线 | TRELLIS.2 mesh distance 相对 degraded input 降低 61.5%，几何差距平均闭合 55.5%；Pixal3D 也改善但并非所有渲染指标最佳 |

### 7. 缺陷、两层根因与证据边界

1. **合成退化不等于开放场景退化**。第一层是退化组合覆盖有限；第二层是现实中的反射、透明、动态遮挡同时改变可见性和成像模型，而合成 pipeline 仍以同一资产 clean view 为答案。于是模型可能学会“识别作者定义的退化”，而不是识别何时视觉证据对三维不可靠。
2. **clean reference 监督把“理想图”当成唯一正确图**。第一层是它要求生成图贴近单一 reference；第二层是同一物体从不同照明/材质条件下可能有多个适合下游的观测，单一 reference 会压制合理多解。
3. **router 的伪标签和 mask 有误差**。Qwen3-VL 审核和 RMBG mask 不是几何真值。错误伪标签会被路由器自强化，净化器则在错误区域获得更大的梯度。
4. **指标盲区**。LPIPS、mesh distance 和渲染指标能说明 output 更接近参考或更自洽，但不能证明不可见表面恢复真实。尤其是“合理但不存在”的补全可能同时降低 LPIPS 和 mesh distance（相对于错误输入），而真实背面仍错。

### 8. 对 amodal 补全、三维重建、三维 amodal 补全的迁移

源机制是“按证据质量决定是否调用先验，并保留来源”。目标同构结构是：amodal 的可见区域是测量，遮挡区域是未知，生成先验只能提供候选。必要条件是显式保存 visible/unknown/generated 三种来源、加入跨视角或深度约束，并让错误补全可被新证据撤销。错配在于 Gate3DGen 的 clean reference 在真实场景通常不可得，UAV 还会多出运动模糊、尺度变化、俯视极端视角和动态遮挡。改造方向是把 router 变成“是否相信补全”的证据路由器，使用可见深度、自由空间、跨视角重投影和不确定度，而不是只看二维退化。

### 9. ARIS 七项诊断

1. **真正问题/缺口**：受损观测使生成器误读视觉线索；现有 2D 修复不以 3D 证据为目标。
2. **为什么需要该方法**：clean bypass 防止干净输入被改坏；冻结下游让输入干预可单独评估。
3. **为什么可能有效**：region/edge 保留身份和轮廓，router features 将退化类型传入 purifier，单步路径降低延迟。
4. **前提与失败条件**：退化可被路由器识别，合成 clean/degraded 对能代表真实，二维约束与三维质量相关。
5. **作者贡献与证据**：方法、数据引擎、两套下游评测均有原文实验；真实照片只有 VLM/人评，缺少真实三维真值。
6. **未解缺口**：真实隐藏几何、路由校准、反事实干预收益、下游多模型迁移尚未充分证明。
7. **研究 idea**：
   - **证据路由器**：保留 clean bypass，把输入分成“可直接测量/需要补全/必须保守”，加入多视角重投影损失。最小实验：20 个双视角遮挡物体；阳性是隐藏误差下降且可见误差不升，阴性说明 router 不是瓶颈，风险是双视角仍不够。
   - **真实多视角监督替代 clean reference**：同一物体两视角，一视角作为 observation，另一视角只作为 delayed evidence；训练 purifier 预测能否解释新视角，而非复制 studio 图。若提升新视角几何，说明 clean-reference 假设是主要瓶颈。
   - **来源分离的三维 amodal field**：分别维护 visible field、uncertain field、generated hidden field；新视角到来时只更新后两者。最小实验是同正面异背面配对，比较单场与三场的 hidden IoU、visible reprojection 和撤销率。

### 10. PaperForge 十二段式

1. 问题重要性：真实照片是 3D 生成部署的主要断点。
2. 相关工作不够：通用编辑优化视觉而非几何，传统前处理只处理单一退化。
3. 反向思路：先判断是否干预，再用一次净化，冻结生成器隔离贡献。
4. 核心直觉：少改；只在证据坏时改；修复要保护轮廓。
5. 输入例子：一张有阴影和遮挡的椅子→router PURIFY→一次 flow→TRELLIS.2→mesh。
6. 公式：路由差分 logit 决定门，flow endpoint 估 clean latent，region/edge 改优化方向。
7. 实验：2D 是否更像 clean？3D 是否更好？路由是否选择性？速度是否下降？
8. 真正结论：在合成退化基准上，输入净化可提升冻结 3D 生成器表现。
9. 最脆弱前提：合成退化和真实退化同构，且 clean reference 是合理目标。
10. 一周复现：只跑公开小配置的 router 混淆矩阵和固定 generator 的输入替换。
11. 最强反例：净化器把真实把手抹掉，生成器因此得到更“典型”但错误的椅子。
12. 非增量后续：做带证据来源和可撤销补全的三维信念路由，而不是更强 2D editor。

## 泛读 1｜OmniRay：先把相机射线弄对，深度才有几何意义

原始出处：[arXiv:2610.31645](https://arxiv.org/abs/2610.31645)，首次公开 2026 年 10 月；只读 HTML，不下载 PDF。

### 先说人话

普通单目深度模型常暗含针孔相机：图像边缘仍被当成“同一种透视”。鱼眼、GoPro、全景图的像素其实对应完全不同的射线，直接套针孔会把场景拉弯。OmniRay 把每个像素的射线方向和沿射线的距离分开预测：先用一个单调径向函数表示大体镜头，再用球谐残差修正平滑偏差，最后用自由形残差补局部变化；距离分支输出 up-to-scale radial distance，二者相乘得到点云。

### 摘要、方法与因果链

【原文事实】DINOv2 编码器驱动 Ray Module 和 Distance Module。Ray Module 依次构建 monotone radial base、spherical-harmonic residual、free-form residual；Distance Module 输出正的 $\rho$，最终 $\mathbf P(u)=\rho(u)\mathbf d(u)$。模型不需要相机内参或 camera-type label，评测包含训练中未见的 GoPro 与 catadioptric 配置。

【基于证据的解释】输入图像→全局 token 估计镜头的大尺度结构→局部 feature 修正残差→射线方向与距离解耦→点云。第一层根因是 pinhole 假设造成系统性射线错；第二层根因是单一固定 basis 同时承担“投影主结构”和“局部畸变”，表达效率和泛化都会受限。分层表示把归纳偏置放在最可能稳定的地方：先用简单结构，再给偏离留自由度。

### 生僻术语

- **Ray field**：每个像素对应的单位射线，不是深度图。删掉它，宽视场下深度误差会被误解释为物体形变。
- **Spherical harmonics**：在球面上展开平滑函数的基；用较少系数描述全局方向偏差。低阶太平滑，无法表达局部镜头误差；高阶则更易过拟合。
- **Geodesic/exponential map on $S^2$**：沿单位球面切空间旋转射线，保证输出仍是单位方向。若直接加向量再归一化，更新方向和角度关系不稳定。

### 实验按问题→设计→答案

| 问题 | 设计 | 答案边界 |
|---|---|---|
| 径向基是否有表达上限？ | oracle fitting 比较 radial、radial+SH、composite | 组合表示降低 ray error；证明表示能力，不等于学习一定成功 |
| 未见镜头能否泛化？ | 多相机训练，GoPro/catadioptric 留出 | 论文报告 SOTA；具体提升依赖数据与相机分布 |
| 距离参数选 $\rho$ 是否必要？ | 宽视场下对比 $Z$ 与 radial distance | $\rho$ 在超过 90° 视场仍可定义；不解决绝对尺度 |

### 缺陷、迁移与 ARIS

镜头表示改善的是**观测几何**，不是隐藏表面推断。第一层缺陷：对 central camera 假设仍然成立；第二层：rolling shutter、动态物体、非中心投影会让“每像素一条固定射线”不再成立。全景图的 ray 正确也不保证背面真实，因为距离仍来自单图先验。

迁移到三维 amodal：把 ray field 作为可见证据坐标，把 occluded field 单独标不确定度；必要条件是相机运动/光学模型在时间上稳定。UAV 的鱼眼和俯视视角可受益，但动态场景和尺度漂移会触发失败。

【ARIS 研究假设】(1) 用 ray uncertainty 作为 amodal 补全置信度，固定物体在不同视场拍摄，检验 ray error 与 hidden reconstruction error 的相关性；(2) 将 radial/SH/free-form 三层残差分别对应测量、可解释畸变和局部不确定区，做残差门控的三维 amodal field；(3) 反事实地把正确 ray 替换为 pinhole ray，固定深度网络，测量 hidden geometry 的变化，判断瓶颈来自相机还是先验。每个 idea 的阳性/阴性结果分别能支持或否定“射线校准是主要误差源”，未运行、未系统查新。

### PaperForge 十二段式与诊断卡

问题重要性是跨相机部署；相关工作用单一 basis 或依赖标定，忽略表示层级；作者设计路径是从 ray decomposition 逐步增加自由度。真实输入例子是鱼眼街景→预测 ray field→预测 $\rho$→点云。公式的关键是 $\mathbf P=\rho\mathbf d$ 和球面指数映射。实验回答“表达能力、未见相机、重建质量”三个问题。最脆弱前提是 central camera 和训练相机覆盖。最强反例是 rolling-shutter UAV 快速转弯；一周最小复现是用合成投影拟合三种表示。非增量后续是把可见射线置信度与三维 amodal belief 一起输出。

| 项目 | 内容 |
|---|---|
| 表面症状 | 宽视场重建弯曲、边缘拉伸 |
| 第一层根因 | pixel-to-ray 映射错 |
| 第二层根因 | 表示把主结构和局部残差混在一起 |
| 方法作用点 | 分层 ray field + radial distance |
| 隐含前提 | central camera、静态成像 |
| 失败触发器 | rolling shutter、动态遮挡、非中心投影 |
| 迁移必要条件 | 可靠 ray uncertainty 与跨视角约束 |
| 反证实验 | 固定深度，仅替换 ray field 比 hidden 误差 |
| 证据边界 | 几何观测更准，不等于隐藏表面更真 |

## 泛读 2｜HiP3R：长视频不是把短视频窗口简单拼起来

原始出处：[arXiv:2610.31635](https://arxiv.org/abs/2610.31635)，首次公开 2026 年 10 月；只读 HTML，不下载 PDF。

### 先说人话、方法流程

长视频通常切成重叠 chunks，每个 chunk 的模型都能给出局部相机和点图，但同一帧在两个窗口里会得到两个不完全相同的相机。只对 chunk 做刚体/相似变换只能摆平整体位置，解决不了窗口内部相机冲突；直接优化所有帧又太贵。HiP3R 先用 Sim(3) 图把 chunks 的全局布局和尺度摆好，再固定布局，为每个物理帧只保留一个共享 SE(3) 相机变量，用重叠窗口的运动和布局先验共同校正。

【原文事实】粗阶段用相邻 overlap 和视觉回环建立 chunk-level Sim(3) pose graph，Huber/IRLS 抑制异常边，逐步引入长距离 loops。细阶段用 shared-camera SE(3) graph，使一个全局帧对应一个相机，结合 placement priors 和 within-chunk motion factors。作者报告在多个公开基准上优于 VGGT-Long，并适用于 streaming backend。

### 深层因果链

局部窗口→独立坐标/重复相机→Sim(3) layout→全局尺度与回环一致→shared frame pose→减少边界跳变。第一层根因是重叠窗口的预测不是同一随机变量；第二层根因是窗口划分改变了上下文，模型误差与不确定度随上下文变化，不能靠单一 chunk transform 消掉。

**Progressive loop scheduling** 先短回环后长回环。它解决非凸优化初始点差的问题；删掉后所有远回环同时进入，错误匹配会把全局布局拖向局部极小。**IRLS/Huber** 让大残差边的影响变小，但会把系统性错误也当 outlier；**shared camera** 把同一物理帧的多次预测合并为一个变量，代价是若真实存在 rolling-shutter 或动态相机，单 pose 反而过强。

### 实验与缺陷

实验问题是“层级图是否同时解决尺度漂移和帧冲突”。设计是跨室内/室外长序列、不同 backend、点采样与回环消融。答案支持轨迹和几何改善、优化成本受控；但它依赖回环检索和 feed-forward pointmap 的质量，没有证明对错误回环的鲁棒性上限，也没有把动态物体造成的几何冲突单独隔离。

两层缺陷：第一，回环边和 overlap 边共享同一错误几何，鲁棒损失只能降低影响，不能创造独立证据；第二，固定 coarse layout 可能把早期尺度错误冻结，细阶段只能在该布局附近修。对 UAV/视频 amodal 的迁移需要把相机轨迹置信度和物体级可见性一起建图，否则把动态物体误差传成相机运动。

### ARIS 与 PaperForge

【研究假设】(1) 在固定回环错误率下比较“固定布局”与“局部解冻”，用可见重投影和隐藏表面跨帧一致性找稳定区；(2) 给每个 frame pose 加 uncertainty，而不是只用 Huber，检验置信度是否能区分动态物体冲突；(3) 共享相机图升级为共享物体轨迹图，输出三维 amodal 物体 belief，遇到新视角时撤销旧隐藏面。最小实验是 100 帧合成轨迹、一个动态遮挡物、三种回环错误率；阳性、阴性、无信号分别解释层级优化是否是瓶颈。

PaperForge 十二段式：重要问题是长时全局一致性；相关工作只做 chunk alignment；设计路径是先尺度布局、后共享帧；真实例子是无人机绕楼飞行→切窗→回环→统一轨迹。公式中的 Sim(3) 残差包含旋转、平移和 log-scale，SE(3) 细图去掉 scale。实验回答全局布局、帧一致和效率。最强反例是错误回环与动态遮挡重合；一周复现是用合成 pose graph 测量 progressive schedule。非增量方向是把“物理帧唯一”扩展为“物体状态唯一但允许多假设”。

| 项目 | 内容 |
|---|---|
| 表面症状 | 长视频漂移、窗口边界跳变 |
| 第一层根因 | 重复局部坐标与冲突相机估计 |
| 第二层根因 | 上下文依赖误差和错误回环共享证据 |
| 方法作用点 | Sim(3)布局→shared SE(3) frame |
| 隐含前提 | 回环大多正确、静态场景 |
| 失败触发器 | 动态物体、错误回环、rolling shutter |
| 迁移必要条件 | 置信度、可见性和物体轨迹分离 |
| 反证实验 | 注入错误回环和动态遮挡，比较解冻/固定 |
| 证据边界 | 证明轨迹一致性提升，不证明隐藏几何真实 |



### ARIS 详细 idea 卡

以下均为【我们提出的研究假设】，未运行、未完成系统查新。

**Idea 1：固定 coarse layout 还是应该局部解冻**

- 方法步骤：在 HiP3R 的两阶段图上加入一个小范围 layout-unfreeze 选项，只允许高置信 overlap 边附近的 chunk 平移/尺度微调；保持 shared-camera 细阶段不变。
- 核心假设：固定 coarse layout 只有在初始尺度正确时才稳定；轻微错误时局部解冻能修复而不引发全局漂移。

- 预期贡献：明确层级图的稳定性/纠错边界。
- 风险：解冻变量增加会引入局部极小。
- 与原论文关系：只改变 Stage I 的约束释放，保留原 shared-camera 设计。

**Idea 2：用不确定度代替单一 Huber 边权**

- 方法步骤：从 point confidence、overlap residual、回环外观相似度学习每条边的方差；在 Sim(3)/SE(3) 残差中使用异方差权重，并对动态区域单独建模。
- 核心假设：错误回环与动态物体会表现为可估计的不确定度，而非单纯大残差。
- 最小验证：加入 10%、20%、30% 错误回环，比较 Huber、IRLS 和 uncertainty-weighted 图。
- 阳性/阴性/无信号：阳性是错误边被降权且真实环闭合保留；阴性说明置信度并不校准；无信号说明主要误差不是边权。
- 预期贡献：把鲁棒优化从残差反应变成证据建模。
- 风险：置信度本身可能由同一错误点图产生。
- 与原论文关系：替换 data-driven edge weight，不改图的层级结构。

**Idea 3：从共享相机扩展到共享物体状态**

- 方法步骤：保留每帧唯一相机，但为每个 tracked object 建立 visible、unknown、generated 三个状态节点；每次新视角只更新 unknown/generated。
- 核心假设：同一物体状态应跨窗口共享，而不应把动态物体误差全部归给相机。
- 最小验证：一条 200 帧 UAV 环绕视频，加入一个移动遮挡物和一个静态背景，比较相机 ATE、物体 hidden IoU、补全撤销率。
- 阳性/阴性/无信号：阳性是物体状态更稳且相机不被动态物体拖偏；阴性说明对象图过强；无信号说明观测不足。
- 预期贡献：长时三维 amodal belief 的图优化接口。
- 风险：object association 错误会传播到全图。
- 与原论文关系：将 shared physical frame 的思想推广到 shared physical object。

## 泛读 3｜F2G-Pose：用密集几何监督换掉候选采样

原始出处：[arXiv:2610.31623](https://arxiv.org/abs/2610.31623)，首次公开 2026 年 10 月；只读 HTML，不下载 PDF。

### 先说人话

类别级 6D 姿态要在没有 CAD、没有参考图、物体被遮挡且同类形状变化很大的情况下，猜旋转、平移和尺寸。F2G-Pose 不先生成一堆姿态候选再挑一个，而是把 RADIOv2.5 的稠密视觉特征投到部分点云上，用 DGCNN 编局部几何，再用 MoE Transformer 汇总全局结构，一次前向同时输出 pose、metric size 和 camera-frame completed shape。

【原文事实】任务网络只用带姿态标注的合成 SOPE 训练，RADIO backbone 冻结。作者报告 SOPE/ROPE 上的 SOTA，pose-only 约 28 FPS，并在 HouseCat6D、HANDAL 和机械抓取实验上评估；形状分支不是额外后处理，而是共享表征的密集几何监督。

### 术语和因果链

**Foundation feature lifting**：把 2D dense feature 按投影取到每个 3D point 上。它把语义外观和米制坐标放在同一 token；删掉后仅靠稀疏深度，类别内形状变化更难区分。投影错、分割错或深度错会把错误语义绑定到错误空间点。

**MoE**：多个专家按 token gate 选择，给不同形状/类别分配不同容量。它的根因假设是“一个统一 FFN 不足以同时处理杯子、工具、对称物体”；但 gate 可能学成类别 shortcut，未必表示真实几何模式。

**Camera-frame shape completion**：预测相机坐标下的完整点集，用于 dense supervision。它能让 pose-size 表征保留范围和方向，但完成的形状仍是由类别先验猜出的，不等于观测真值。

### 实验按问题→设计→答案

| 问题 | 设计 | 答案边界 |
|---|---|---|
| 直接单次预测能否替代采样/候选提取？ | SOPE/ROPE 与 GenPose++ 诊断 | 精度和速度支持直接路线；不证明所有多模态姿态都可压成一个答案 |
| 几何辅助是否有用？ | pose/size/shape 联合与消融 | 形状监督改善共享表征；需要看类别和遮挡分层 |
| 是否可部署？ | HouseCat6D、HANDAL、抓取 | 说明 segmented RGB-D 下有潜力；不等于开放场景无分割部署 |

### 缺陷与迁移

第一层缺陷是单次回归会把对称性和遮挡多解压成均值或 mode；第二层是损失函数默认存在一个可用标签，因而对“两个旋转都合法”的结构性歧义没有概率表达。合成 SOPE 到真实 HANDAL 的域差还包含深度噪声、材质和分割误差，冻结 RADIO 不能消除它。

迁移到 amodal：形状 head 可作为 visible/hidden 分解的起点，但必须把完成点的来源和置信度拆开；三维 amodal 中应同时监督可见点重投影、自由空间和完整形状候选。UAV 小目标和稀疏深度会让 feature lifting 不稳定。

【ARIS idea】(1) 把单一 shape head 改成 3 个隐式候选，加入对称等价损失，测 hidden coverage 与 pose calibration；(2) 注入投影错/深度错，反事实比较 lifting 与纯 RGB，找空间绑定是否为真正瓶颈；(3) visible shape 固定、hidden shape 多假设，跨视角新证据只更新 hidden 分支。每个 idea 都先做 20 类合成小实验，不启动 GPU。

### PaperForge 十二段式与诊断卡

重要问题是实时类别级姿态；相关工作要么中间结构误差传播，要么 diffusion 候选采样慢；作者路径是 foundation feature→局部几何→MoE 全局→pose/size/shape 联合。真实例子是遮挡杯子 RGB-D→投影 feature→DGCNN/MoE→姿态、尺寸、完整点集。公式核心是 point-feature lifting、6D rotation 和 shape loss。实验回答速度、精度、形状辅助和抓取。最强反例是完全对称的碗或同类双峰尺寸；一周复现是冻结 backbone 的 synthetic noise stress test。非增量后续是概率化的 visible/hidden pose-shape belief。

| 项目 | 内容 |
|---|---|
| 表面症状 | 姿态错、尺寸偏、补全点云平滑 |
| 第一层根因 | 部分观测与类别内变化 |
| 第二层根因 | 单标签回归无法表达对称多解 |
| 方法作用点 | 2D-3D lifting、MoE、shape auxiliary |
| 隐含前提 | 分割/深度/类别标签可靠 |
| 失败触发器 | 对称、透明、深度缺失、域偏移 |
| 迁移必要条件 | 多假设、可见性来源和跨视角约束 |
| 反证实验 | 对称物体等价姿态的校准与 hidden IoU |
| 证据边界 | 类别级姿态和相机坐标形状提升，不证明 amodal 真值 |



### ARIS 详细 idea 卡

以下均为【我们提出的研究假设】，未运行、未完成系统查新。

**Idea 1：多假设 pose/shape 是否比单一回归更适合对称物体**

- 方法步骤：保留 F2G-Pose 的 lifted feature、DGCNN、MoE；将 pose-size head 改为 3 个隐式候选，并用 symmetry-equivalent minimum loss 训练；shape head 对每个候选输出 camera-frame completion。
- 核心假设：对称性和遮挡产生结构性多解，单一 L2 回归会得到不存在的平均姿态。
- 最小验证：10 个类别、每类含旋转对称和双峰尺寸对象，比较 deterministic 与 3-hypothesis 的 pose calibration、hidden IoU、抓取成功代理。
- 阳性/阴性/无信号：阳性是候选覆盖提高且可见误差不升；阴性说明数据中的歧义并不影响决策；无信号说明评测只包含单一标签。
- 预期贡献：把直接回归路线扩展到可校准三维 amodal belief。
- 风险：候选选择重新引入后处理成本。
- 与原论文关系：保留单次 backbone，改变输出分布而非回到扩散采样。

**Idea 2：反事实投影错误诊断**

- 方法步骤：固定 RGB 和真实点云，逐步注入相机内参、深度 scale、分割 mask 的错误；分别关闭 feature lifting、只用 RGB、使用错误 lifting。
- 核心假设：2D-3D lifting 是性能的因果作用点，投影错会比纯 RGB 更严重地破坏 hidden completion。
- 最小验证：20 类 SOPE 合成对象，三档每种扰动，固定随机种子。
- 阳性/阴性/无信号：阳性支持空间绑定是关键；阴性支持 foundation feature 主要靠语义；无信号说明模型忽略了被扰动输入。
- 预期贡献：分离语义 backbone 与几何绑定的真实收益。
- 风险：合成扰动不覆盖真实深度传感器伪影。
- 与原论文关系：使用其模块做反事实，不新增训练目标。

**Idea 3：visible/hidden 双场形状头**

- 方法步骤：将完整 shape 分成可见点场和隐藏候选场；visible field 用观测深度和轮廓强约束，hidden field 输出 3 个候选；新视角只重加权 hidden field。
- 核心假设：把已测量部分和类别先验分开，能减少生成的 hidden geometry 反过来改坏 visible pose。
- 最小验证：20 个同正面异背面物体，比较 RGB-only、RGB-D、双场的 visible reprojection、hidden IoU、topology error。
- 阳性/阴性/无信号：阳性是 visible 稳定且 hidden coverage 提升；阴性说明隐藏先验不足；无信号说明 pose/decoder 是瓶颈。
- 预期贡献：将 F2G 的 shape auxiliary 转成三维 amodal 表示。
- 风险：需要可靠 visible/hidden 标注或合成真值。
- 与原论文关系：保留 dense geometric supervision，增加来源分离和多假设。

## 泛读 4｜FlexPart：把点、框、mask 当成不同强度的几何证据

原始出处：[arXiv:2610.31671](https://arxiv.org/abs/2610.31671)，首次公开 2026 年 10 月；只读 HTML，不下载 PDF。

### 先说人话与摘要

同一个物体，有人只想点一下“这条腿”，有人能给框或精细 mask。已有 3D part 方法通常只支持一种提示粒度，换输入就要换模型或牺牲空间控制。FlexPart 把 point、box、mask 编成统一条件，用 Gated AdaLN 调制 DiT；再让强的 box/mask 表征通过 stop-gradient 和 partial optimal transport 去教弱的 point 表征。

【原文事实】PartVerseXL mask 条件下 Part CD 相比 TripoSG+SAM3D 降低 16.6%，相比 OmniPart 降低 10.5%。模型以 TripoSG/3D VAE 初始化，分两阶段训练，PartVerseXL 与 PartObjaverse-Tiny 做 held-out 评测；point-only 仍明显比 box/mask 差。

### 方法、术语和因果链

提示→modality encoder→null embedding 处理缺失→Gated AdaLN 调制 DiT→part latent→mesh。随机 dropout 让模型见过缺失/混合提示。强提示→Visual Bridge→teacher feature；point→student feature；partial OT 用全局竞争和 dustbin 处理 unmatched prior→对角 alignment loss。

**Gated AdaLN** 不是简单拼接条件，而是在每层学习 scale、shift、gate，允许网络决定“这一层要听多少几何提示”。删掉 gate，强提示可能过度覆盖图像语义；gate 过强则弱提示学不到结构。

**Partial OT/Sinkhorn** 把点到 box/mask 的匹配视为整体分配，而不是每个点独立找最近邻。它解决 many-to-one collapse；dustbin 允许没有对应的 prior。它并不保证 prompt 本身语义正确，只是在错误 prompt 上更稳定地匹配。

### 实验、缺陷、迁移

实验问题是“统一多粒度是否同时保留精度和灵活性”。设计包括 main table、stop-gradient、partial OT 对比、点位置敏感性、SAM cascade 和人类 prompt。答案支持 mask/box/point 的统一模型，但 part-level 指标先做 Hungarian matching，并排除完全遮挡 GT parts、对 unmatched 不罚，这会高估交互成功率。

第一层缺陷：提示粒度变化被当成 representation alignment 问题；第二层：不同粒度可能不是同一语义的不同噪声，而是用户对 part 边界的不同意图。teacher mask/box 也可能错误，stop-gradient 保护了 teacher 但无法修正错误先验。对 amodal 的迁移价值是把可见 mask、框和点当成不同强度证据，但隐藏 part 不能只靠 2D prompt 补齐；需要 3D 可见性、跨视角和拓扑约束。

【ARIS idea】(1) 用同一个 part 的 visible mask、occlusion mask、depth interval 做三路 prompt，测试强/弱证据是否应分开对齐；(2) 构造错误 box/mask 的反事实，测 partial OT 是纠错还是把错误全局传播；(3) 让生成 part 带来源标签（observed/propagated/generated），新视角出现时撤销 generated geometry。最小实验每个只用 50 个 PartObjaverse 物体，不启动训练。

### PaperForge 十二段式与诊断卡

重要问题是交互式 part 生成；相关工作提示粒度固定或先 SAM 再 lift；作者路径是统一条件→跨模态 gate→强先验教弱先验。真实例子是用户点椅腿→可选框→可选 mask→生成 part mesh。公式核心是 null embedding、Gated AdaLN 和 partial OT。实验回答多粒度精度、鲁棒性、分配和用户提示。最强反例是用户有意只点“扶手末端”而数据标签认为整条扶手，指标把意图当错。非增量后续是“意图层级+可见/不可见 part belief”联合生成。

| 项目 | 内容 |
|---|---|
| 表面症状 | 点提示下 part 边界漂移、mask 下较好 |
| 第一层根因 | 证据粒度不一致 |
| 第二层根因 | prompt 语义和数据 part 标签可能错位 |
| 方法作用点 | Gated AdaLN、partial OT |
| 隐含前提 | 不同粒度指向同一 part |
| 失败触发器 | 错框、边缘点、完全遮挡 part、用户意图差异 |
| 迁移必要条件 | 来源/不确定度、3D可见性、拓扑约束 |
| 反证实验 | 同一视觉区域的不同用户意图对比 |
| 证据边界 | part generation 指标提升，不证明完整隐藏 part |



### ARIS 详细 idea 卡

以下均为【我们提出的研究假设】，未运行、未完成系统查新。

**Idea 1：可见 mask、遮挡 mask 和深度区间的三路提示**

- 方法步骤：在 FlexPart 的 point/box/mask 条件旁加入 visible mask、occlusion mask、depth interval；用 Gated AdaLN 分层调制，不把未知区域直接当作空白。
- 核心假设：同一 2D 区域的“看见”“被挡住”“深度不确定”是不同证据，不应共享一个 mask token。
- 最小验证：50 个 PartObjaverse 物体，合成三种遮挡比例，比较单 mask 与三路 prompt 的 visible IoU、hidden IoU、topology error。
- 阳性/阴性/无信号：阳性是隐藏 coverage 提升且 visible 不降；阴性说明提示分离没有信息；无信号说明生成器成为瓶颈。
- 预期贡献：把 variable granularity 从交互控制扩展到 amodal 证据控制。
- 风险：深度区间标注成本高。
- 与原论文关系：沿用 modality encoders 和 Gated AdaLN，新增证据类型。

**Idea 2：错误 prompt 的反事实传播**

- 方法步骤：保持图像不变，分别对 box 偏移、mask 膨胀、point 移到边缘；比较 row-wise matching、strict OT、partial OT 的错误传播。
- 核心假设：partial OT 的 dustbin 能减少 unmatched collapse，但不能自动纠正语义错误。
- 最小验证：20 个对象、四种 prompt 错误、冻结模型特征匹配，不训练。
- 阳性/阴性/无信号：阳性是 partial OT 降低 many-to-one 且不扩大错误区域；阴性说明 global competition 反而传播错误；无信号说明 prompt 误差太小。
- 预期贡献：明确 OT 的纠错边界。
- 风险：错误 prompt 与真实用户意图难分。
- 与原论文关系：直接使用其 stop-gradient/partial OT 诊断设置。

**Idea 3：带来源的 part belief**

- 方法步骤：每个 part latent 附带 observed、propagated、generated source；新视角只更新 generated/propagated；当新 mask 与旧 part 冲突时保留多个候选。
- 核心假设：来源分离能避免生成隐藏部件被后续视角误当成观测。
- 最小验证：同正面异背面 50 个物体，测 hidden coverage、visible reprojection、撤销成功率。
- 阳性/阴性/无信号：阳性是错误 part 可撤销且可见区域稳定；阴性说明来源标记没有约束到 decoder；无信号说明新视角没有揭示差异。
- 预期贡献：交互式三维 amodal part completion。
- 风险：多候选 latent 的存储和匹配开销。
- 与原论文关系：从统一提示生成扩展到可更新的 part 状态。

## 泛读 5｜Video World Survey：从“看懂视频”转向“维护一个会变化的世界状态”

原始出处：[arXiv:2610.31668](https://arxiv.org/abs/2610.31668)，首次公开 2026 年 10 月；只读 HTML，不下载 PDF。

### 先说人话

这篇综述最有用的不是列模型，而是把视频看成潜在世界的片段投影：视频是 partial、lossy、temporally ordered observation。作者把研究分成 reading（从视频读出世界属性）、writing（按条件写出视频）、sharing（理解和生成共享表征）、interacting（在动作和新观测下更新状态）。这四个词把“画面看起来连贯”和“世界状态真的一致”分开。

### 摘要、方法与关键术语

【原文事实】综述定义 latent world $W$、observed video $V$、represented state $s_t$，区分 trace coherence 与 world consistency，并按 prediction space（observation/latent）和 transition interface（passive/action-conditioned/interactive）分类 world model。开放问题集中在 long-horizon consistency、physical/causal grounding、统一模型的可测 synergy、标准化评测、跨场景泛化和稀有事件。

【基于证据的解释】第一层问题是视频模型能预测下一帧；第二层问题是它是否维护一个在遮挡、视角变化和动作干预下仍可用的状态。若只用像素或语言答案监督，模型可以在短期视觉上连贯，却没有被迫记住不可见物体、接触关系和因果变量。

**Reading/Writing/Sharing/Interacting** 是功能分解，不是四个互斥网络。删掉“sharing”会失去理解与生成之间的共同状态接口；删掉“interacting”则无法检验状态是否能支持行动。

### 对 amodal 与三维重建的迁移

amodal 补全本质上也是“从部分观测维护隐状态”。把可见 mask、深度、相机和时间作为 observation，把完整物体/场景作为 state，把新视角或 UAV 移动当成 action/observation update，可以把一次性补全改成可更新 belief。必要条件是记录来源和不确定度，而不是把生成像素当新测量。失败触发器包括动态物体、视角断裂、传感器缺失和长期误差自强化。

### 实验/证据边界

这是 survey，不提供单一新模型的主实验；它的证据来自跨任务文献和评测协议比较。它真正回答的是“哪些性质应被评估”，不是“哪一种架构已经解决世界建模”。综述的分类本身也会受到代表性文献选择和快速变化领域的影响。

### ARIS idea

1. **Amodal belief benchmark**：同一物体用视频逐帧揭示遮挡，评测 belief calibration、hidden IoU、可见重投影和撤销率，而不只看单帧 PSNR。最小实验是 20 个可控三维物体、三条相机轨迹。
2. **反事实状态测试**：固定历史视频，在某帧插入不可能的遮挡/动作，检查模型是否更新 hidden state 还是继续沿用旧幻觉。阳性/阴性/无信号分别对应状态更新、记忆惯性或测试太弱。
3. **三维 amodal world model**：用显式可见场、隐藏场和动态场三路 latent，动作只更新可能受影响的场；一周内先做小型 Gaussian/voxel 版本，不跑大模型。

### PaperForge 十二段式与诊断卡

问题重要性是把视觉模型与世界状态区分开；相关 survey 往往按任务/架构分类，缺少 observation→state→action 统一链。作者路径是先定义 world/video/state，再用四种操作组织文献。真实例子是无人机视频看到被遮挡车辆→读出可见几何→维护隐藏 belief→下一帧更新→规划绕行。公式重点是 $x_t\sim\mathcal O(\cdot|w_t,\pi_t)$ 和 $w_{t+1}\sim\mathcal T(\cdot|w_t,a_t)$，它们把相机配置与动作从世界状态中分离。实验答案是评测维度和研究缺口。最强反例是像素视频完美连贯但物体身份/物理关系错误。非增量后续是可被新证据撤销的三维 amodal state benchmark。

| 项目 | 内容 |
|---|---|
| 表面症状 | 视频连贯但遮挡后对象状态错 |
| 第一层根因 | 只优化观察/语言输出 |
| 第二层根因 | 没有可被动作和新观测检验的隐状态 |
| 方法作用点 | world/video/state 分离，四操作分类 |
| 隐含前提 | 状态可由视频部分恢复且评测可构造 |
| 失败触发器 | 动态、多解、长期滚动、稀有事件 |
| 迁移必要条件 | belief、不确定度、跨视角更新 |
| 反证实验 | 不可能遮挡/动作插入后的状态更新 |
| 证据边界 | 综述提出框架，不证明某模型已解决世界建模 |


### ARIS 详细 idea 卡

以下均为【我们提出的研究假设】，未运行、未完成系统查新。

**Idea 1：视频 amodal belief benchmark**

- 方法步骤：为同一物体设计遮挡逐步揭示的多视角视频；记录 visible mask、depth、camera pose、真实完整 mesh 和每次新证据；评测 hidden IoU、belief calibration、visible reprojection、撤销率。
- 核心假设：单帧 PSNR 无法衡量模型是否维护了可更新的世界状态。
- 最小验证：20 个可控三维物体、三条相机轨迹、两种遮挡动态。
- 阳性/阴性/无信号：阳性是新证据使 hidden belief 有序收敛；阴性说明静态单帧指标已足够；无信号说明轨迹没有揭示多解。
- 预期贡献：把 video world model 的状态一致性转成三维 amodal 可测协议。
- 风险：benchmark 可能过度理想化。
- 与原论文关系：落实 survey 的 partial/lossy observation 与 world consistency 区分。

**Idea 2：不可能动作/遮挡反事实**

- 方法步骤：固定历史视频，在某帧插入违反物理或身份连续性的遮挡/动作；要求模型输出 state update、uncertainty 和下一视角预测。
- 核心假设：真正的 hidden state 会拒绝不可能证据或提高不确定度，纯生成模型会继续平滑续写。
- 最小验证：10 个物体、20 个反事实片段、冻结一个视频模型或显式 voxel baseline。
- 阳性/阴性/无信号：阳性是检测到冲突并提高 uncertainty；阴性是无条件续写；无信号表示反事实强度不足。
- 预期贡献：失败诊断而非单纯性能提升。
- 风险：反事实编辑本身引入视觉伪影。
- 与原论文关系：从 survey 的 physical/causal grounding 挑战提出可运行测试。

**Idea 3：三维 amodal world state**

- 方法步骤：用 visible field、hidden field、dynamic field 三路 latent 表示场景；相机移动更新 visible/hidden，动作只更新可能受影响的 dynamic field；解码时输出观测和三维 mesh。
- 核心假设：来源和时间分离能阻止生成幻觉在长时滚动中自强化。
- 最小验证：小型 voxel/Gaussian 场景、100 帧、一个移动遮挡物，比较单 latent 与三 field 的 hidden IoU、drift 和撤销率。
- 阳性/阴性/无信号：阳性是长期 drift 降低且可见重投影不变；阴性说明分离造成容量损失；无信号说明短序列不足以暴露自强化。
- 预期贡献：把 survey 的 reading/sharing/interacting 具体化为三维 amodal 状态接口。
- 风险：状态分解和动态关联错误会增加复杂度。
- 与原论文关系：不是综述声称的已有方法，而是从其分类和开放问题推导的后续方向。
