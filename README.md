# 每日 CV 文献更新

这是一个自动整理计算机视觉前沿文献的个人研究仓库，重点关注 **COD、UAV、烟雾分割**，同时发散跟踪异常检测、开放世界视觉、视觉基础模型、多模态、具身智能、生成模型等方向。

## 每日更新

- **1 篇精读**：优先选择有公开代码、创新明确、全文和实验可核验的高质量论文。
- **5 篇泛读**：总结核心问题、主要机制、研究价值、迁移思路和证据边界。
- 生僻概念会使用面向初学者的中文进行解释。
- 每篇论文分别分析其对 COD、UAV 和烟雾分割的潜在价值。
- 每天 00:00（Asia/Shanghai）自动执行，并将结果提交到 GitHub。

只有精读论文会下载 PDF 并导入本机 Zotero；泛读论文只保留文字记录和原始链接，不下载全文。

## 目录

- `docs/md/YYYY-MM-DD.md`：每日 5 篇泛读。
- `docs/md/longform/YYYY-MM/`：按月归档的精读长文。
- `docs/html/`：每日 HTML 预览。
- `data/`：论文列表、每日记录和月度精读索引。
- `research/selection-log/`：选文顺序和筛选依据。
- `research/audit/`：PDF、Zotero、Git 和失败项审计。

## 当前规则

文献结论分为“论文直接证据”“基于证据的推断”和“待验证研究假设”，避免把发散想法写成事实。精读 PDF 只有在核验 Zotero 条目、日期集合、子附件关系和实际存储文件后，才会标记为导入成功。

最新内容可从 [`docs/index.html`](docs/index.html) 或 [`docs/literature.md`](docs/literature.md) 查看。
