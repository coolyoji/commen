# UniAS：让异常分割真正关注“异常像素”

## 论文定位

论文：**Towards Accurate Unified Anomaly Segmentation**，WACV 2025。

来源：[arXiv:2501.12295](https://arxiv.org/abs/2501.12295)；代码：[Mwxinnn/UniAS](https://github.com/Mwxinnn/UniAS)。本次已下载并读取 PDF，确认摘要、引言、方法、主实验和消融；它符合“有代码、有明确创新、可复现”的精读条件。

## 一句话总结

UniAS 指出：异常分割不能只看 AUROC，因为异常像素很少时，背景真阴性会把 AUROC 抬得很高；它用多层级重建、Transformer 的全局关系和多粒度门控 CNN 的局部细节，降低异常掩码的假阳性和边界错误。

## 小白先懂三个词

**AUROC** 可以理解为“把异常分数排序的能力”：正常像素和异常像素能不能大体排开。但它不直接告诉我们掩码边界是否准确。在异常区域只占很小比例时，大量背景像素会让一个有很多假阳性的模型仍得到很高 AUROC。

**pAP** 是像素级平均精度，更关心被模型标成异常的像素里有多少真的异常；**DSC** 是 Dice 相似系数，直观上衡量预测区域和真实区域的重合程度。对分割任务，这两个指标比只看 AUROC 更接近“画出来的区域能不能用”。

**One-for-All** 指一个模型同时学习多个类别或多个物体的正常分布，而不是每个类别单独训练一个模型。优点是统一、节省部署成本；难点是不同类别的正常纹理差异很大，模型容易把正常细节误认为异常。

## 任务设定

训练阶段只输入没有异常的图像，模型学习正常数据的特征分布。测试阶段输入正常或异常图像，输出像素级异常图。论文主要在 MVTec-AD 和 VisA 上评估，并把“图像级发现异常”和“像素级准确分割”区分开。

## 作者真正发现了什么

论文先做了一个很重要的评价诊断。MVTec-AD 和 VisA 的平均异常像素比例约为 13.17% 和 3.00%，也就是说背景像素远多于异常像素。在这种不平衡下，一个模型只要把异常像素排在大致靠前的位置，就可能有不错的 AUROC；但它仍可能在背景上画出大片错误区域。论文给出的示例显示，UniAD 的 AUROC 很高，但 pAP 和 DSC 很低，说明“排序看起来对”不等于“掩码画得对”。

这个问题对烟雾分割很有启发：烟雾早期往往只占很小区域，云、雾、灰尘和反光又容易制造大量背景假阳性。只报告 AUROC 或像素准确率，很可能掩盖“画错一大片背景”的失败。

## 方法详解

### 1. 多层级特征重建

主干网络输出多个层级的特征。高层特征分辨率低、语义强，适合判断“这里是否像异常”；低层特征分辨率高、边缘细，适合确定异常边界。UniAS 不把所有特征先压到最低分辨率，而是从粗到细逐层重建正常特征，再将原始特征与重建特征的差异转成异常图。

它解决的是旧方法的一个失败：先把所有特征下采样到同一低分辨率，再重建，细小裂纹或窄边界已经丢失。删除多层设计后，论文消融的 pAP/DSC 从完整模型的 65.12/59.33 降到 40.14/25.24；只补回多层重建后，提升到 56.47/39.06，说明层级信息不是装饰。

### 2. Transformer + MGG-CNN 混合模块

Transformer 在这里负责全局关系：一个位置可以参考远处位置，适合理解物体整体结构和长距离依赖。CNN 则擅长局部纹理和边缘。论文提出 **Multi-Granularity Gated CNN（MGG-CNN）**，用不同感受野提取多种尺度的局部细节，再通过门控把有用尺度组合起来。

对小白来说，“门控”就是让网络学会决定哪一路信息该放大、哪一路该压低，而不是把所有卷积结果机械相加。它的输入是当前层的特征，输出是带有局部边界信息的重建特征；删除门控或改成单个普通卷积，模型会更难区分真正异常边界与正常纹理。

论文消融显示，逐渐加入普通卷积、无门控多粒度 CNN、MGG-CNN 后，pAP/DSC 继续提高；作者因此认为，多感受野本身有用，但门控对融合这些尺度同样重要。

### 3. Sample-Aware Reweighted Query（SAR）

One-for-All 模型面对不同类别时，固定随机查询不一定适合每个样本。SAR 根据当前样本重新加权查询，让重建模块更贴近该样本的正常结构。它解决的是跨类别正常分布差异过大的问题。删除 SAR 后，模型仍能工作，但类别间的重建误差更不稳定。

### 4. 异常图生成

每一层都比较原始特征和重建后的正常特征，得到该层异常图；再将不同层、不同粒度的异常信号聚合。高层信号有助于抑制语义上的错误响应，低层信号补充精确边界。最后再用阈值把连续异常分数变成二值掩码。

论文实现中按每类 PR 曲线选择分割阈值，以最大化 precision 与 recall 的和；这点需要警惕，因为部署时阈值可能无法用测试标签重新选择。真实应用应在独立验证集上校准阈值。

## 实验证据

在 MVTec-AD 上，UniAS 达到 **65.12 pAP / 59.33 DSC**；在 VisA 上达到 **40.06 pAP / 32.50 DSC**。论文还报告 AUROC 仍保持较高水平，并通过消融证明多层重建、MGG-CNN 和 SAR 各自提供增益。

这些结果支持两个结论：第一，单纯追求 AUROC 会漏掉假阳性问题；第二，提升分割质量需要保留低层细节，而不是只强化高层语义。不能直接把工业异常数据上的数值当成烟雾分割性能，因为烟雾具有透明、运动和时序变化，域差异明显。

## 深度批判

第一，论文的异常主要来自工业和物体表面，异常边界相对稳定；烟雾边界会随风扩散，重建误差可能反映运动而不是异常。第二，按每类 PR 曲线选阈值会使用类别信息，跨场景部署时需要重新校准。第三，One-for-All 的“正常分布”假设在烟雾场景更脆弱：云、雾、蒸汽可能本来就是正常背景，但外观与烟相似。

论文最值得迁移的不是直接换数据集，而是评价方法：烟雾分割必须同时报告早期召回、边界 F1、每帧误报率、时序抖动和 mIoU，不能只报一个 AUROC。

## 对当前课题的迁移

### COD

**假设**：用多层异常图和存在性拒识可以减少“背景纹理被当成伪装物”的假阳性。最小实验是保持主干和训练集不变，只加入 pAP/DSC 评价与多层分支，对比负样本 FPR。若 pAP 上升但纯背景 FPR 不降，则说明多层重建没有解决开放世界拒识。

### UAV

**假设**：低层高分辨率异常图能改善小目标边界，但高分辨率分支会增加端侧开销。按 4、8、16 像素目标分层，比较 pAP、边界 F1、FPS 和显存。如果 4 像素目标召回没有改善，说明低层特征仍被主干下采样抹掉。

### 烟雾分割

**假设**：多层重建可同时保留早期细烟的弱信号和大烟团的全局形状；但必须加入时间一致性与难负例。最小实验使用无烟云雾、灰尘、蒸汽、夕阳反射和真实烟雾短视频，比较 mIoU、边界 F1、早期召回、每帧 FPR 和时序抖动。若加入多层后早期召回提高但云雾 FPR 同时大幅升高，应转向“多层异常图 + 存在性门控”，而不是继续堆网络。

## 精读结论

UniAS 是一篇值得认真复现的文章，真正有价值的创新是把“评价指标失真”和“特征分辨率损失”连成了一个完整问题。对当前课题，优先复现它的指标诊断和多层特征消融，再决定是否把 MGG-CNN 迁移到烟雾分割；不要直接把工业异常检测结构当成烟雾模型。
