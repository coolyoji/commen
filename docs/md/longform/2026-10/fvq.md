# FVQ：重建误差为什么不等于语义损失，“语义无损”又不能推出什么

原始出处：[arXiv:2610.37662v1](https://arxiv.org/abs/2610.37662)，标题 *Can Discrete Tokens Serve as Semantically Lossless Representations of Visual Signals?*；预印本首发 **2026 年 10 月**，阅读归档 **2026 年 10 月**，当前按预印本引用，不虚构正式会议。官方实现：[hustvl/FVQ](https://github.com/hustvl/FVQ)，核验提交 `5c5c97d7564adb10f079a7c46b39018a815a4654`，存在模型、训练、配置、示例和测试文件，未运行代码。

## 1. 先说人话与问题重要性

把视觉特征变成离散编号，好处是图像可以像文字一样进入统一 token 系统。担心也很直接：连续向量被有限词表替代，误差越大，模型是否越不理解图像？

论文先给出反例：某个离散表示重建原特征的 MSE 更差，却能让问答模型答得更好。原因不能简单归为“丢掉噪声”。更根本的是**重建器与任务解码器解决不同问题**：前者要恢复每个特征分量，后者从编号学习与答案有关的结构。使两个向量的每个坐标接近，与保留“这一个小数字究竟是什么”并不是同一目标。

FVQ 的改造是：不要让新增码本只处理越来越小的残差，也不要把输入切得越来越窄。让每个码本都从完整特征得到固定维度的互补投影，平行量化，再让下游学习编号的含义。

## 2. 摘要拆解、相关方法和两层根因

【论文原文事实；§2】作者把多模态理解成绩作为 semantic fidelity 的代理，发现 MSE 不能可靠排序任务表现；增加比特预算有帮助，但 RVQ/PQ 在较大码本组数下趋于饱和。FVQ 采用固定稠密 tight-frame projections、并行码本和紧框架合成，延缓这一饱和。

【基于证据的解释】RVQ 的第一层问题是后面的码本只收到前面没解释掉的残差；第二层是“有更大词表空间”与“新增变量携带独立任务信息”不同，残差能量下降不保证剩余关键信息被稳定编码。PQ 的第一层是分组越多，输入通道越窄；第二层是通道划分不等于语义因子划分，跨通道组合可能被拆断。

FVQ 并没有证明 RVQ 后段都没用：Table1 的 odd/even 组合恰恰说明少量残差码也可能携带丰富任务信息。应读成“结构性地让新增码本持续得到完整来源的信息”，不能读成“残差必然不重要”。

相关工作地图：VQ 是单码本对照；RVQ 按残差层级编码；PQ 按通道分组编码；ViQ、UniAR、Emu3 是离散多模态比较对象；Qwen3-VL 为强连续模型参照。原文 §2、§4 和文献表给出出处。工业系统横向比较训练配方不同，不能把全部差距归因 FVQ。

## 3. 反向设计路径和核心直觉

【基于证据的解释，非作者思维记录】从“量化误差就是语义损失”的假设出发，先检查 MSE 与理解是否一致；发现排序不一致，再把容量改为独立控制变量；发现增加组数仍饱和，才回到各码本实际输入的信息结构。这比先发明模块、再只报总体成绩，更容易问出设计究竟解决了哪个瓶颈。

核心直觉有三点。多个码本应看到同一特征的不同组合，而不是越往后只看到更弱的剩余量。新增码本的输入维度保持固定，避免容量增长时信息来源反而变窄。投影整体先不要丢信息，但后续量化是否保住任务信息仍需实验，不能由线性代数直接宣布。

## 4. 用一张表格图走完整 pipeline

【说明性输入例子】图中有一个很小的单元格数字“545”，问题要求读取它并作比较。冻结视觉基础模型先把图片分成 patch 特征；训练 tokenizer 的输入投影把特征变为 $z_i$。每个固定矩阵 $R_\ell$ 都混合完整特征通道，得到固定维度的一份 view。各码本选择最近 codeword，产生一组离散 ID。

【论文原文事实；§3–4、Fig.3】tokenizer 训练时，codewords 通过 tight-frame synthesis 与 feature decoder 重建冻结视觉特征，使用特征重建、码本与 commitment 类目标；不是像素生成监督。完成后冻结 tokenizer，重新初始化视觉 token embeddings，训练 embeddings/merger 与语言空间对齐；随后进行预训练和 SFT。最终 VLM 读的是**离散 ID 对应的新 embeddings**，不是 tokenizer 重建出的特征。

【基于证据的解释】因此，MSE 衡量一条训练支路，问答依赖另一条解码路径。若某些低能量方向足以区分“545”和“550”，平均坐标误差小不代表该方向保留；反之，一组 ID 可以被任务 decoder 充分利用，即使固定 feature decoder 没把所有坐标重建好。

## 5. 公式、变量和实际约束

【论文原式；§3.2，Eq.1–3】$z_i\in\mathbb R^D$，每个 view 维度 $d$，码本数 $L$，单码本大小 $C$：

$$
u_{i,\ell}=R_\ell z_i,\qquad
A^\top A=\rho I_D,\qquad \rho=\frac{Ld}{D}.
$$

矩阵 $A$ 由所有 $R_\ell$ 纵向堆叠。$Ld\ge D$ 时，可用固定高斯矩阵的 reduced QR 构造列正交结构，再缩放；训练期间投影固定。tight frame 的含义是所有特征方向总能量被同样缩放，没有一个非零方向被所有 views 同时抹掉。

$$
k_{i,\ell}=\arg\min_{j\in\{1,\ldots,C\}}
\|u_{i,\ell}-c_{\ell,j}\|_2^2.
$$

每个码本选择最近 codeword；并行是计算结构，**不意味着各编号统计独立**。名义预算为 $B=L\log_2 C$。当 $C=16384$、$L=16$，是每 patch 224 名义 bit，不是实际压缩文件每 patch 的熵，也不是互信息的实测值。

$$
\hat z_i=\frac1\rho\sum_{\ell=1}^{L}R_\ell^\top c_{\ell,k_{i,\ell}},
\qquad
\frac1\rho A^\top A z_i=z_i.
$$

等式右半说明**量化前**可精确恢复。左半用了最近 codewords，误差仍在。tight frame 排除了“投影本身共同漏掉某方向”，没有排除“有限码本把该方向的多个值映射到同一 ID”。

【基于证据的解释】量化训练把离散码拉向可重建特征；commitment 约束输入表示与所选码别反复跳离；后续语言训练赋予这些码具体任务用途。若视觉 teacher 原本就把两个不同隐藏形状编码成相同特征，任何确定性量化都无法恢复已不存在的区分。这是数据处理的限制，不是换更多码本即可突破。

## 6. 术语解释和模块因果链

**Semantic fidelity**：本文以问答/OCR等成绩代理语义保真，不是全部视觉任务的充分统计量。**Tight frame**：多个可能冗余的线性测量，整体对所有方向等比例保能量；不是每个测量都完整，也不是量化后无损。**Codebook collapse**：很多样本集中选少数编号，名义词表大、实际使用容量小。**Commitment**：约束编码结果靠近所选码；删掉可能让码与输入分布不稳定。**Merger**：将多组 ID 的 embeddings 组织成下游输入，不能把码本数量直接等同语言 token 序列增长倍数。**Effective bit budget**：作者强调新增码应有用；仅列 $L\log_2 C$ 不足以实测“有效”，需编码使用率、相关性与下游增量信息验证。

| 模块 | 输入证据→中间表示→信号/损失→行为→目标→失效触发器 |
|---|---|
| 固定 VFM | 图像→语义 patch 特征→teacher 的既有训练→确定信息上限→提供可编码视觉内容→teacher 不敏感的细几何无法凭空恢复 |
| 稠密投影 | 完整特征→固定维度 views→tight-frame 约束→多码本都有全通道来源→缓解结构性输入衰减→views 可能仍高度冗余 |
| 并行 VQ | views→离散 ID→码本/commitment 与特征重建→有限划分→离散接口→稀有小差别落入同一码 |
| Embedding/merger | ID 组→任务 embeddings→对齐、预训练、SFT→让解码器读出有关信息→理解表现→数据/解码容量及训练预算错配 |

## 8. 贡献与真正留下的结论

可核验贡献是：以受控对照挑战 MSE 代理；指出码本数量与有效信息不同；给出保持各码本输入来源的 FVQ 结构；展示从较小共享配置到工业系统的结果。真正有启发的结论是：**量化器不应仅以“能重建原向量”评价，还需检查下游究竟读取哪些信息。**

“Semantically lossless”是研究问题和作者经验性主张，应限定为测试任务、模型和配方。连续特征已包含离散 ID 能用到的一切确定性信息，离散系统胜过某个有限连续 baseline，可来自归纳偏置、正则、数据与解码优化；不能证明量化创造了 teacher 没有的信息。

## 9. 缺陷为什么存在，最脆弱前提是什么

1. **语义任务覆盖不足。** 第一层是大多测问答/OCR；第二层是这些标签对连续几何和不可见结构不敏感，两个不同三维场景可能有相同答案。指标没有区分它们，均值高不能证明对应、深度或隐藏拓扑保真。
2. **名义容量不等于有效容量。** 第一层是码本可能相关或低利用；第二层是所有 views 来自同一 teacher，新增投影可重复表达相同潜变量。并行码本各自查询，不构成统计独立证明。
3. **重建与任务目标仍错配。** 第一层是 tokenizer 冻结后 decoder 另训；第二层是训练信号只奖励标签可识别信息，未出现的稀有几何因子可持续被忽略。把重建目标替换为语义目标，也会换一组盲点。
4. **尺度和复现受预算限制。** 第一层是工业 token 量大；第二层是量化结构、训练资料与优化路径共同决定表现，普通预算无法隔离相同因果。

最脆弱前提是“当前理解基准足以代表目标视觉信息”。它对于文档读取可能有力，对于毫米级几何、遮挡边界或完整物体体积则尚无直接证据。

## 10. 迁移到 amodal、重建和三维 amodal 的深层条件

【我们提出的研究假设】

| 目标 | 源机制与目标同构结构 | 必要条件 | 错配、改造、失败触发器 |
|---|---|---|---|
| 二维 amodal | 多码本避免单一瓶颈吞掉弱但关键轮廓线索 | teacher 保留边界/目标身份，具完整mask监督 | VQA语义不等于遮挡轮廓；需可见/隐藏mask分支与边界损失。相似语义但不同轮廓会失败。 |
| 三维重建 | 多个互补测量保留定位所需特征方向 | 位置、相机、尺度和跨视角对应不被量化抹除 | 全局语义teacher可能忽略metric深度；需重投影、深度/法线及对应约束。纹理相似但视差不同为强反例。 |
| 三维 amodal | 离散表示可组织多个完整形状假设 | 有完整shape先验、观测来源和不确定性监督 | 同正面不同背面在输入上不可辨识；需多假设occupancy/SDF与后来视角更新，不能给单一“无损”真值。 |

能迁移的深层原因是**目标任务也有“信息编码→有限接口→专门解码器”的瓶颈**，可以检验哪些方向被浪费、哪些方向必须保留。不能直接迁移的根本原因是观测不充分和 teacher 任务不一致：编码更好只减少人为损失，不消除真实世界的不可观测多解。

## 11. ARIS 三个深层 idea、一周计划与反例

全部为**待验证研究假设**，未运行、未通过完整查新，不能把方法草案写成已获性能。

### Idea A｜等 MSE，不同任务方向

**方法步骤：**固定特征、decoder 和数据，找出与已标注任务有关的局部方向；在该方向与正交方向加入等能量扰动；匹配 MSE、bit预算、decoder参数和训练步数，比较问答与几何误差。对方向估计使用独立训练/测试分割。

**核心假设：**同样 MSE 对任务的影响取决于误差方向，FVQ 优势可能来自更均匀保留弱任务方向。**最小实验：**一周内对已缓存特征做小型探针和受控扰动；先从无需大模型训练的分类/深度线性探针开始，不承诺复现工业VLM。**阳性：**等MSE仍有稳定任务差距，支持目标错配解释；**阴性：**方向不改变结果，当前teacher/task可能近似各向同性；**无信号：**探针太弱或方向估计过拟合，不能称机制成立。**贡献：**把MSE失效从相关性推进为受控诊断。**风险：**探针方向未必等同真实LLM使用方向。**关系：**细化原文Table1反例，挑战把“误差不重要”说得过宽。

### Idea B｜新增码本到底增加了信息还是重复编码

**方法步骤：**记录码使用率与组间条件相关；每次移除/打乱一组ID，另用复制已有组替代，保持接口和decoder容量；测其条件增量任务价值，并对名义bit进行分层。

**核心假设：**真正有用的码本应在其他组已知时仍提供可读取的新信息，单看 $L\log_2 C$ 不够。**最小实验：**使用缓存ID训练同规模小探针，做真实新增组、重复组、乱序组对照；不以高维互信息点估计作为唯一证据。**阳性：**新增组有独立增益而复制无效，支持互补机制；**阴性：**复制组也获得相同收益，提示decoder容量或训练效应混淆；**无信号：**所有探针饱和或失效，需调整任务而非硬下结论。**贡献：**区分名义容量与任务有效容量。**风险：**组删除导致分布外输入，应重训匹配探针对照。**关系：**检验FVQ关于有效bit的解释，不声称统计独立已经成立。

### Idea C｜为三维 amodal 建立几何敏感离散接口

**方法步骤：**将可见几何与形状先验分开编码；在可见支路约束位置、相机、深度和重投影；隐藏支路输出多个occupancy/SDF候选；新视角只依据实际显露区域更新权重。

**核心假设：**task-aware量化应保留可观测几何，隐藏区域则保留多解，而非以VQA保真替代完整形状保真。**最小实验：**用现成完整mesh构造同正面异背面对象；先比较连续特征、普通VQ和FVQ的低成本几何探针，再在固定候选集上做新视角更新。分别测可见误差、隐藏IoU、真值候选覆盖与校准。**阳性：**可见几何不退化且新证据减少错误隐藏候选；**阴性：**问答相近但几何退化，证实语义代理不足；**无信号：**teacher本身不能区分几何或候选没有真实多样性。**贡献：**明确语义离散化通往完整形状推断的适用边界。**风险：**完整shape真值、位姿和预算约束；需先用真值相机隔离。**关系：**借鉴FVQ接口，新增几何监督与可观测性目标，原文没有证明。

**一周安排：**优先做A的等误差离线诊断，其次B的缓存ID反事实，C先完成合成数据与指标检查。三条都不需要从头训练工业模型；实际运行仍需明确资源授权。

**最强反例：**两个物体正面相同、背面结构不同，teacher特征与所有ID完全相同。问答全对也不能唯一判断背面。**非增量方向：**研究“对哪些任务、在什么可观测条件下足够”的离散接口，并能用新测量推翻隐藏假设，而不是宣称一个码本同时保住所有世界信息。

## 12. 深层诊断卡

| 项目 | 诊断 |
|---|---|
| 表面症状 | 离散化后理解下降，增加码本后收益饱和 |
| 第一层根因 | 单码本容量、残差衰减、窄通道分组 |
| 第二层根因 | 向量重建目标与任务信息错配；名义容量和独立有效信息不同 |
| 方法作用点 | 输入views、码本对称性、量化前保能量结构与下游解码 |
| 隐含前提 | teacher含目标信息，当前理解基准代表目标保真 |
| 失败触发器 | 小几何差异、跨视角错位、稀有码/相关码、未知背面 |
| 迁移必要条件 | 几何敏感teacher、坐标/相机约束、完整shape监督与不确定性 |
| 反证实验 | 等MSE异方向；复制/打乱码组；同正面异背面 |
| 证据边界 | 有限VQA/OCR基准及工业配方；无直接几何/amodal实验，未独立复现 |

**精读结论：**最值得带走的不是“离散终于无损”，而是先问损失了什么、由谁读取、用什么实验能看见这种损失。重建好、回答好和完整三维正确，是三个相关但不能互相替代的目标。
