# 跨领域泛读与非模态补全迁移规则

生效阅读月份：2026 年 10 月。每天仍为 1 篇精读和 5 篇泛读；五篇泛读的主要职责是发现其他领域中可能用于非模态补全的机制。精读继续保留完整原文核验、Nature Reader、ARIS 和 Zotero 流程。

## 按问题结构找方法

检索先问非模态补全缺少什么能力，再寻找其他领域如何处理相同结构。不能只检索标题包含 amodal、completion、occlusion 或 reconstruction 的论文。优先选择有可提取机制、可查全文、能设计最小迁移实验的工作，经典方法可与近期工作结合，不强求全部为最新论文。

每天五篇尽量来自至少三类方法家族；不能把同一类模型换五个应用算作多样性。每周轮换来源，避免连续被生成模型、三维视觉或同一骨干占满。证据不足时缩小推荐强度，记录检索缺口，不能为凑领域编造关联。

下表是检索种子及待检验的迁移理由，不是某类方法已对 amodal 有效的结论。

| 来源领域或机制 | 值得检验的结构对应 | 关键错配与应问的问题 |
|---|---|---|
| 逆问题、贝叶斯推断、数据同化 | 从部分观测提出多个完整解，再以观测更新 | 成像算子、似然和先验是否正确？后验多样性是否只是噪声？ |
| 缺失数据、因果推断、选择偏差 | 遮挡使证据按形状和视角选择性缺失 | 缺失是否依赖隐藏形状？随机掩码训练能否代表真实遮挡？ |
| 图学习、组合表示、程序化建模 | 可见部件与隐藏部件共享关系或结构约束 | 部件图能否辨识，拓扑先验是否排除了真实形状？ |
| 等变表示、对称性、几何学习 | 形状随视角变化的表示需保持一致 | 物体真有该对称性吗？镜像补全是否错误复制不对称结构？ |
| 概率预测、校准、集合预测 | 相同可见部分可能支持多个隐藏解释 | 应输出多解还是单点？覆盖率提高是否只是候选无限增加？ |
| 机器人主动感知、信息增益、规划 | 新视角可能区分当前不可判定的候选 | 哪次观测真的减少形状歧义？动态物体和运动成本如何处理？ |
| 视频记忆、跟踪、状态估计 | 过去显露的表面可约束当前遮挡 | 对象身份、变形和时间对应可靠时才能复用，如何防止错误记忆传播？ |
| 物理推断、接触、可微仿真 | 支撑、接触和可行结构可能缩小候选集 | 物理可行不等于实例真实；材料与边界条件错误会排除真解吗？ |
| 多模态对齐、跨模态蒸馏 | 深度、触觉或语言可提供不同来源约束 | 是新增测量还是语义先验？位置、尺度与身份如何对齐？ |
| 压缩、量化、信息瓶颈、检索 | 保留弱但决定隐藏形状的证据或调用形状先验 | 语义保真是否掩盖细几何损失？检索是否只复制常见原型？ |
| 自监督、能量模型、生成式推断 | 学习完整结构先验并接受观测约束 | 合理生成与真实恢复如何区分？生成结果能否被后来观测推翻？ |

以上范围开放。优化、数值计算、医学成像等领域只要存在可验证的结构对应，也应纳入检索。

## 每篇必须回答为什么选它

在原有摘要、术语、方法、贡献、实验、缺陷、ARIS ideas 和诊断卡之外，加入以下迁移论证。可以与原有章节合并，但不能省略实质内容。

1. **源问题与两层根因。** 原论文解决什么失败，直接原因是什么，更深层是可观测性、表示、目标函数、训练信号还是系统约束？
2. **目标中的对应结构。** 在二维非模态、三维重建或三维非模态中，哪一个具体环节存在相同问题？指出原论文变量与目标中的变量，不能只说“都存在遮挡”。
3. **迁移的因果链。** 写出“目标输入证据 → 拟引入的表示 → 训练信号/约束 → 推理行为变化 → 预期改善”，解释哪条链条有原文支持，哪条仍是假设。
4. **必要条件与最危险错配。** 检查相机、可见性、身份对应、动态变化、完整标注与先验覆盖。若源任务假设随机缺失，目标却是结构相关遮挡，必须解释这会如何改变学习目标。
5. **具体改哪里。** 给出一个非模态输入例子，说明插入哪个模块、改哪些输入输出和损失、需要何种监督、保留哪些观测硬约束，以及额外成本。只写“加入扩散/图网络/物理约束”不算完成。
6. **最小判别实验。** 对比直接使用原方法、目标改造、删除关键机制，并匹配参数、数据与计算预算。说明阳性、阴性、无信号各自能排除哪些解释。
7. **最强反例与推荐判断。** 指出何种样本会使该迁移失败；给出高优先试验、有条件试验或仅供启发的判断及依据，不能给无依据的成功概率。

每篇至少有一个直接面向非模态补全的可执行方案。三方向都要明确适用性；对某方向没有可靠对应时写清原因，不能硬造三套用法。

## 区分三种任务结果

- **二维非模态补全：**完整 mask、隐藏边界或被挡部分外观。需要说明输出是哪一种，不能相互替代。
- **三维重建：**从实际观测恢复几何和相机。表面重建好不代表从未显露的部分正确。
- **三维非模态补全：**推断完整实例，包括不可见表面或体积。必须区分观测证据、学习先验和不可辨识多解。

评估同时关注可见部分是否受损、隐藏部分是否正确、跨视角一致性和不确定性；涉及主动观察时，再检查新观测能否淘汰错误候选。只给全局 IoU 或生成图的视觉质量不足以验证全部迁移主张。

## 记录与审计

选文依据、每日 Markdown 和 `research/aris/YYYY-MM-DD.json` 均保留源领域、方法家族、推荐理由、可迁移机制、目标改造、必要条件、最强反例、最小实验和证据状态。`research/selection-log/YYYY-MM-DD.json` 同时解释当天五篇的方法多样性；未能达到至少三类时记录实际原因。

所有迁移内容区分“论文原文事实 / 基于证据的解释 / 我们提出的研究假设”。未运行的实验和未经系统查新的 ideas 不写成已验证效果或已确认创新。
