# DAPS｜Improving Diffusion Inverse Problem Solving with Decoupled Noise Annealing

原始出处：[arXiv:2407.01521v3](https://arxiv.org/abs/2407.01521v3)；首发 **2024 年 7 月**；正式发表：CVPR 2025；阅读归档：**2026 年 10 月**。官方实现：[zhangbingliang2019/DAPS](https://github.com/zhangbingliang2019/DAPS)，本批核验提交 `0b182726f84df1ad26fde4dccebefda4747b82d8`，存在可读实现但未运行模型。

> 证据标记：`论文原文事实`来自论文正文、表格、公式或官方代码；`基于证据的解释`是对因果机制的拆解；`我们的研究假设`是向二维 amodal、三维重建和三维 amodal 的迁移方案。没有把迁移想法写成论文结论。

## 1. 先说人话：它真正解决什么问题

给定一个观测 `y`，例如相位恢复或 HDR 测量，想找一个既符合数据又像真实图像的 `x`。这类 Bayesian inverse problem 往往不是“从输入直接回归唯一答案”，而是存在多个解释。扩散模型提供图像先验，但普通后验采样沿着连续反向扩散轨迹逐小步修正：早期如果进入错误模态，后面仍只在附近挪动，最终得到一个看起来像图像、却不符合正确全局解释的解。

**论文原文事实：**DAPS（Decoupled Annealing Posterior Sampling）将相邻时间步解耦，在每个噪声水平近似采样观测条件下的时间边缘分布，再逐渐降低噪声。作者在 phase retrieval、HDR、inpainting、deblurring 等任务报告了更好的样本质量和稳定性，尤其强调复杂非线性测量。

**深层问题：**表面上是“PSNR 不够”；第一层根因是局部更新不能跨越错误的全局模态；第二层根因是采样路径的状态依赖把早期错误当作后续搜索的起点，导致观测梯度只能做局部修补。这个问题与非模态补全中的“一个可见前面对应多个完整背面”具有结构同构性，但前向观测算子和隐藏变量必须重新定义。

## 2. 相关工作为什么不够、作者设计路径是什么

**论文原文事实：**既有方法通常在 diffusion sampling 过程上加 data consistency 或 posterior correction；连续时间步之间仍高度耦合。DAPS 改变的是 annealing path，而不是简单再加一个损失项。

**反向重建作者思路（基于证据的解释，不是作者访谈）：**

1. 如果错误主要来自早期模态锁定，继续缩小步长不会解决全局搜索问题。
2. 想让不同噪声水平的样本自由变化，就不能只把 `x_{t-1}` 当作 `x_t` 的小扰动。
3. 每个噪声水平仍须满足同一个观测约束，因此要采样的是相应的条件时间边缘，而不是任意跳跃。
4. 精确边缘难算，于是用先验项、measurement likelihood 和 Langevin dynamics 近似；更便宜的 conditional Gaussian 近似用于工程实现。

核心直觉有三句：**先验负责“像什么”，观测似然负责“必须解释什么”，解耦退火负责“不要被上一步的错误模态绑死”。**它增加的是后验探索能力，不是凭空增加测量。一个样本满足先验与观测，只能说明它是合理解释，不能说明它就是隐藏真值。

## 3. 真实输入走完整 pipeline

以 phase retrieval 为例，真实图像 `x*` 经过非线性前向算子 `A` 产生观测 `y=A(x*)+n`，其中相位被丢失。DAPS 的一轮推理可以写成：

1. 预训练 diffusion prior 提供当前噪声水平下的 `p(x_0|x_t)` 或 score。
2. 使用候选 `x_0` 通过 `A(x_0)` 生成预测观测，并计算与 `y` 的 likelihood。
3. 将先验梯度和观测梯度合成未归一化后验的 Langevin 更新，加入噪声探索多个候选。
4. 在当前噪声水平得到近似条件样本，再把它送到下一噪声水平；相邻样本不要求小幅连续。
5. 重复直到噪声接近零，输出一个或多个后验样本。

迁移到“桌子挡住椅背”的图像时，不能把 `A` 仍理解为相位测量。应将 `A` 改为：给定完整 mask/mesh、相机、深度和遮挡者，渲染出**可见目标证据**；被遮挡区域不能被错误地当作目标观测。观测似然只应约束已见轮廓、深度顺序、自由空间和跨视角一致性，未知背面保留多解。

## 4. 公式、变量含义和优化行为

Nature Reader 中的公式锚点为 `E001`–`E004`。论文的条件分解可概括为：

`p(x_0 | x_t, y) ∝ p(x_0 | x_t) p(y | x_0)`。

`x_0` 是干净候选，`x_t` 是噪声状态，`y` 是观测，第一项由 diffusion prior 给出，第二项由 measurement likelihood 给出。Langevin 更新在候选上同时沿两种梯度移动，并注入随机噪声。噪声退火则控制从高噪声的广泛探索逐步进入低噪声的精细约束。

**因果链：**观测证据 `y` + 先验样本 → 候选完整状态 `x_0` → 先验/似然梯度与噪声 → 在条件后验中探索 → 产生多样且更符合观测的解释 → 当 forward operator 错、先验不覆盖、步长/混合不足时失败。

删除 measurement likelihood，模型会生成漂亮但与观测不符的图；删除 prior，逆问题会变成噪声敏感的欠定拟合；删除 Langevin 噪声或把步长压得过小，候选难以跨模态；步长过大则可能偏离后验。把 Gaussian approximation 当成精确后验也会掩盖多峰和强相关。

## 5. 实验到底回答了什么

**论文原文事实：**FFHQ phase retrieval 的 PSNR 为 30.72 dB，HDR 为 27.12 dB；高分辨率 latent 实验报告 31.49 dB。作者还报告 conditional Gaussian 近似相对 diffusion-score 估计约快 6–7 倍，但任务质量存在依赖任务的下降。数值来自作者实验，本机未独立复现。

这些实验回答的是：在论文所选先验、噪声模型、采样预算和前向算子下，解耦退火能改善逆问题重建。它们没有回答：

- 非模态 mask 或完整 mesh 是否能被同样机制正确恢复；
- 隐藏区域多解是否被校准；
- 一个“合理后验样本”是否对应真实背面；
- 错误遮挡者身份、相机标定或动态物体时是否稳健。

因此不能把 PSNR 提升直接改写成 amodal IoU 或隐藏 Chamfer 提升。

## 6. 缺陷为什么存在：两层根因

### 6.1 观测似然可能是结构性错配

第一层：如果把遮挡物像素当作目标的观测，似然会把错误区域硬拉进候选。第二层：真实遮挡是结构相关缺失，缺失概率依赖目标形状、遮挡者和视角；错误 forward operator 不仅增加噪声，而是把不同物体的解释权混到一个变量里。更多 Langevin 步数只会更充分地优化错误目标。

### 6.2 先验覆盖不足与多峰坍缩

第一层：diffusion prior 可能生成训练分布中的常见形状，却没有真实物体的细部。第二层：两个合法隐藏形状可能在可见区完全相同，输入本身不可辨识；再强的先验只能按数据分布选一个偏好，不能证明它是真值。

### 6.3 近似、成本与评价盲区

Gaussian approximation 以计算换准确度；多峰后验可能被单峰近似压扁。PSNR 允许局部平均，无法反映拓扑断裂、细杆漏检或跨视角不一致。高分辨率 latent 结果也不能替代真实三维证据。

## 7. 为什么可以迁移到三个目标

| 目标 | 源机制 | 目标同构结构 | 必要条件 | 最危险错配 |
|---|---|---|---|---|
| 二维 amodal | 后验探索多个观测一致候选 | 可见轮廓约束 + 隐藏 mask 多解 | 完整 mask 训练监督、可见/未知/非目标三态标记 | 把遮挡物像素当目标证据；逐像素平均破坏拓扑 |
| 三维重建 | likelihood 与 prior 联合约束逆解 | 深度/射线/多视角证据 + 形状先验 | 相机标定、深度噪声模型、跨视角对应 | 错相机使“数据一致”变成错误几何 |
| 三维 amodal | 保留多个完整形状后验并接受新视角更新 | 可见表面固定、隐藏表面多候选 | 形状先验覆盖真解、候选支持域、真实新观测 | 单一可见面对应不同背面；候选平均成不存在的物体 |

迁移的深层原因不是“都用了 diffusion”，而是二者都面对**由不完整观测约束的多解逆问题**。真正需要改的是变量、forward operator、损失和评价：DAPS 的采样路径可借用，像素恢复的观测模型不能照搬。

## 8. PaperForge 风格十二段式检查

1. **问题和实际重要性：**非线性逆问题中的早期模态锁定会让小步后验采样无法全局纠错。
2. **相关工作为何不够：**只在相邻 denoising step 上加局部一致性，不能改变路径的局部性。
3. **反向重建作者思考路径：**把“后续只能修一点”改成“每个噪声水平重新探索条件边缘”。
4. **核心直觉：**prior 负责合理性，likelihood 负责证据，decoupling 负责跨模态。
5. **真实输入 pipeline：**测量 `y` → 先验候选 → 前向算子 → likelihood → Langevin → 退火。
6. **公式来源、变量和优化：**`x_0,x_t,y,A` 分别是候选、噪声状态、观测和前向算子；梯度竞争决定样本往哪里走，噪声决定探索。
7. **按问题→实验设计→答案：**复杂非线性测量上比较采样质量和稳定性，结果支持所选设置下的后验探索改进。
8. **论文真正留下的结论：**采样路径设计会决定逆问题是否能跨模态，不是 diffusion prior 自动解决一切。
9. **最脆弱隐含前提：**`A` 和噪声似然可靠，先验覆盖目标分布，计算预算足以混合。
10. **一周最小复现实验：**在低分辨率合成相位恢复和双峰形状任务上比较普通耦合、DAPS 式解耦与无 likelihood 消融。
11. **最强反例：**两个物体可见前面完全相同而背面不同；单一观测无法判断哪一个是真值。
12. **非增量后续方向：**让候选形状保留“可被新视角否证”的后验，并把主动观测成本纳入决策，而不是只输出最漂亮的单解。

## 9. 三个 ARIS 深层 idea

### Idea A｜后验探索替代单点补全

**方法：**输出多个完整 mask/mesh 候选；可见区域用重投影、深度和遮挡顺序作硬约束；未知区保留候选分布。对比单点扩散、DAPS 式后验采样、候选平均。

**假设与实验：**同一可见证据对应多种隐藏拓扑时，候选覆盖优于单点平均。使用合成完整形状和配对遮挡，匹配参数、候选数和采样步数；报告隐藏 IoU/Chamfer、可见违约、拓扑合法率和真值候选覆盖。阳性是候选各自合法且覆盖真解；阴性说明任务近似单峰；无信号需检查候选是否真的多解。

### Idea B｜结构化 forward operator

**方法：**把目标可见 mask、确知自由空间、遮挡者深度和相机写入观测模型；对比错误像素算子、结构化算子和无 likelihood 消融。

**假设与实验：**真正的瓶颈是证据归属而非扩散容量；在同等采样预算下结构化算子能降低可见约束违约，但错标定会造成系统性错误。实验只改变遮挡者几何/相机误差，保持先验和候选预算不变。

### Idea C｜新视角反证候选

**方法：**保存多个完整形状假设，按每个候选在可达新视角下的观测似然更新权重；新视角只在真实显露区域淘汰冲突候选。

**假设与实验：**主动新证据比在单视角上继续采样更能减少后验多解。比较随机视角、覆盖最大视角和候选分歧最大视角，固定移动成本和渲染预算；报告候选淘汰率、隐藏误差下降和动作成本。若所有视角对候选都不可区分，应报告“不可辨识”，而不是强行选一个。

## 10. 深层诊断卡

| 项目 | 结论 |
|---|---|
| 表面症状 | 重建看似合理，但遇到非线性/遮挡时模态错误 |
| 第一层根因 | 相邻采样只能做局部修正，或观测项没有正确约束 |
| 第二层根因 | 路径锁定、结构相关缺失、不可观测多解和前向算子错配 |
| 方法作用点 | 解耦时间边缘、后验 likelihood、Langevin 探索 |
| 隐含前提 | 先验覆盖、观测模型可靠、采样预算足够、候选支持真解 |
| 失败触发器 | 错遮挡身份、错相机、动态物体、单峰近似、多解被平均 |
| 迁移必要条件 | 观测/未知分离、完整监督来源、多候选评价、跨视角或主动证据 |
| 反证实验 | 同前面异背面；错误 forward operator；候选平均拓扑断裂 |
| 证据边界 | 原文验证图像逆问题；三种非模态迁移均为未运行研究假设 |

## 精读结论

DAPS 最值得借鉴的是“把补全看成受证据约束的后验探索”，而不是把扩散结果当作唯一真相。迁移到非模态补全时，首先要保证观测模型知道哪些像素属于目标、哪些只是遮挡物，随后才谈采样路径；否则更强的采样只会更彻底地解释错误问题。
