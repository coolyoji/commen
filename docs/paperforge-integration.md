# PaperForge 阅读流程接入说明

PaperForge 的中文版 `SKILL_CHN.md` 提供了一套适合深度论文阅读的十二段式框架。我们把其中适合计算机视觉研究的部分接入每日任务，并与 Nature Reader、ARIS 和本仓库的深层分析规范合并。

## 每篇精读和泛读新增的思考顺序

1. 研究问题和实际重要性。
2. 相关工作已经做到什么，为什么仍然不够。
3. 反向重建作者的思考路径：先前的失败现象、经验观察和理论线索如何导出该方法。
4. 用两到四句话说清核心直觉。
5. 用一个真实输入例子走完整 pipeline。
6. 若有实质数学，逐步解释公式的来源、变量含义和优化行为。
7. 按“问题 → 实验设计 → 得到的答案”解释实验，而不是只罗列指标。
8. 提炼论文真正留下的结论。
9. 找出最脆弱的隐含前提，并说明它失效时哪条因果链会断。
10. 设计一周内可运行的最小复现实验。
11. 设计能真正挑战论文主张的最强反例。
12. 基于最脆弱前提提出一个非增量的后续研究方向。

## 与现有流程的分工

- **Nature Reader**：负责原文、章节、图表、公式和页码锚点，保证“论文写了什么”可追溯。
- **PaperForge 结构**：负责“作者为什么这样设计、实验到底回答了什么、哪个前提最危险”。
- **ARIS**：负责跨论文调研、缺口诊断和可执行 idea，明确区分论文事实、证据解释和研究假设。
- **深层分析规范**：负责根因、因果链、迁移必要条件、失败触发器和反证实验。

## 迁移到 amodal 和三维任务时的强制问题

每篇论文都要回答：

- 它解决的是观察不足、表示错误、目标函数错配、时空对应错误，还是评价指标盲区？
- 源论文的机制在 amodal 补全或三维重建中对应哪个结构性问题？
- 迁移需要保留哪些证据、几何关系、可见性状态或时间对应？
- 目标场景中哪些条件会让迁移失效？
- 最小复现实验和最强反例分别是什么？
