## 精读：PoinTr

PoinTr 的 point proxy、geometry-aware Transformer block、dynamic query 和 multi-scale point generation 让“长程结构、局部几何、缺失位置、局部采样”分工更清楚。它在 ShapeNet 完整真值上验证了结构化点集生成，但 KITTI 只有 Fidelity/MMD 代理，不能把 plausible completion 当作隐藏实例真值。迁移重点是把单一缺失 query 改为带来源的候选 query，并用自由空间、跨视角重投影和后到观测做可撤销重评分。完整分析见 [精读长文](longform/2026-11/pointr.md)。

## 五篇泛读

### 1. MIWAE: Deep Generative Modelling and Imputation of Incomplete Data

用 observed-data likelihood 和多重插补处理缺失训练数据；迁移价值在于把未知区当作条件分布而不是伪标签。

**为什么能迁移：** 用 observed-data likelihood 和多重插补处理缺失训练数据；迁移价值在于把未知区当作条件分布而不是伪标签。

**最危险错配：** 训练/测试缺失机制可被当前模型或校正的 mask 描述。真实遮挡是 MNAR，缺失概率依赖未知几何；若训练只用 MCAR，MIWAE 可能把结构性缺失当随机抽样。

**具体目标 pipeline：** 被箱子挡住的椅子 RGB-D + visible/occluded/background mask → 编码器产生 $q(z|x_{\rm obs},m)$ → 解码器只在 observed pixels/depth 上计算似然，未知区采样多个 occupancy/appearance 候选 → 每个候选通过可见投影和自由空间检查 → 输出二维 mask 集合、可见三维表面和完整三维候选。目标输入例子中，遮挡者 mask 不应进入椅子外观似然，否则模型会把遮挡者当椅子的一部分。

**最小实验：** 固定一个 RGB-D encoder 与参数预算，比较 zero-fill VAE、MIWAE mask-aware、MIWAE 加结构相关 mask。用 40 个椅子、相等可见率、三种缺失机制，输出 hidden mask IoU、visible violation、3D Chamfer、候选 coverage 和 calibration。阳性：只在结构缺失上改善且 visible 不退化；阴性：候选更像类别原型但实例错误；无信号：mask 机制尚未成为瓶颈。

**反例与证据边界：** 两张椅子可见前腿完全相同，隐藏侧分别有横梁和断开支架；同一 mask、同一 RGB-D。MIWAE 只能表达两个后验候选，不能从 observed likelihood 选真解。 缺失数据可以通过对 observed likelihood 做生成式学习来避免直接伪造缺失标签。它留下的是条件分布建模机制，不是完整真值恢复保证。

三项未运行 idea：MNAR-aware MIWAE; 候选覆盖而非单次插补; 观测替换反事实。

### 2. Neural Processes

用 context set、global latent 和 conditional decoder 快速表达函数级不确定性；迁移价值在于把可见表面当 context、未知位置当 query。

**为什么能迁移：** 用 context set、global latent 和 conditional decoder 快速表达函数级不确定性；迁移价值在于把可见表面当 context、未知位置当 query。

**最危险错配：** context 点是 exchangeable 且能代表任务，target 位置与 context 共享坐标。动态物体、相机误差、遮挡者混入和无标定多视角会破坏这个对应。

**具体目标 pipeline：** 多视角可见点/像素、深度、相机位姿 → context encoder 逐观测编码 → set aggregation 得到对象级 latent 分布 → query 是未知像素/体素位置及射线 → decoder 输出 occupancy/appearance 分布 → observed surface 固定为硬证据，unknown 区保留多个 sample。二维任务输出完整 mask 候选，三维任务输出 SDF/occupancy sample。

**最小实验：** 20 个程序化杯子，每个首帧只露出杯身，target 是隐藏杯柄位置。对比 Deep Sets、NP、NP+camera/ray tokens。固定参数和 context 数，测 hidden F-score、NLL、coverage、visible IoU。阳性：后验覆盖增加而 visible 不退化；阴性：方差变大但候选都错；无信号：对象族过于单峰。

**反例与证据边界：** 同一个前表面对应有柄、无柄、双柄三个实例，任何 target query 都有同一 context；NP 的方差只能表达不确定性，不能凭空增加真实性。 集合 context 可以支持快速函数后验近似，global latent 提供任务级不确定性。它不保证对结构相关缺失、三维拓扑或实例身份进行正确建模。

三项未运行 idea：Context dropout 后验; 多视角 latent consistency; 置信度拒答。

### 3. Graph Matching Networks for Learning the Similarity of Graph Structured Objects

用 cross-graph attention 在比较时联合推理结构对应；迁移价值在于将多视角部件匹配从独立 embedding 提升为证据注入。

**为什么能迁移：** 用 cross-graph attention 在比较时联合推理结构对应；迁移价值在于将多视角部件匹配从独立 embedding 提升为证据注入。

**最危险错配：** 图节点和边具有稳定身份。真实点云过分割、部件消失、相机位姿错和同纹理物体会让 attention 把不同实例对齐。

**具体目标 pipeline：** 视角 A 的可见部件图、视角 B 的可见部件图及候选完整部件图 → 节点输入局部几何/颜色/visibility state，边输入接触和相对位姿 → GNN 内传播 → cross-graph attention 产生匹配证据 → 只合并高置信已观测部件，unknown 节点留在候选 → 用重投影和自由空间更新完整三维。

**最小实验：** 构造 30 个两椅子场景，节点为部件片段，边为接触/相对位姿。比较独立 GNN、GMN、GMN+unmatched。固定图规模和训练步数，测 correspondence precision、hidden part F-score、visible violation 和候选 coverage。阳性：只在跨视角对应正确时 hidden F-score 提升；阴性：attention 复制错误纹理；无信号：节点本身已足以解决。

**反例与证据边界：** 两把同色同形椅子交叉遮挡，部件图相同但身份不同；cross-graph attention 可能获得漂亮但错误的跨实例匹配。 图匹配的有效表示必须在 pair 内联合推理。它没有证明跨图对应在遮挡下可识别，更没有证明匹配后的隐藏形状是真实例。

三项未运行 idea：Unmatched-aware GMN; 反事实身份交换; 后到视角重匹配。

### 4. RAFT: Recurrent All-Pairs Field Transforms for Optical Flow

用 all-pairs correlation 和 recurrent updates 反复修正稠密对应；迁移价值在于传播有来源的时序观测，但必须加身份与深度门控。

**为什么能迁移：** 用 all-pairs correlation 和 recurrent updates 反复修正稠密对应；迁移价值在于传播有来源的时序观测，但必须加身份与深度门控。

**最危险错配：** 高相关像素是同一实体。遮挡边界、重复纹理、相同对象穿越、相机跳变和非刚体会使 flow “稳定地错”。

**具体目标 pipeline：** 视频中被行人挡住的椅子 → RAFT 得到前后向 flow 与 confidence → 用深度、目标 mask、相机运动筛选同一表面的 valid correspondences → 将历史观测写入当前 object-centric shape state → 新显露帧更新未知候选。遮挡者交叉或同色对象时，flow 只能作为候选而非硬监督。

**最小实验：** 生成 30 段八帧椅子遮挡序列，含重显露、同色交叉和相机跳变。固定 RAFT、门控改造和无 flow 三种预算，测 flow EPE、ID switch、hidden F-score、visible violation。阳性：重显露后门控模型更快纠正候选；阴性：WE 下降但 ID 错；无信号：所有动作都没有额外可辨视角。

**反例与证据边界：** 两把相同椅子互相遮挡，光流从一把腿平滑地跟到另一把腿；时序一致性和 EPE 都很好，三维身份却错误。 全对全相似度和迭代更新能提高二维运动对应；这一机制适合当时序证据提取器，不等于三维形状恢复器。

三项未运行 idea：Flow + depth/ID gate; 新显露撤销实验; Correlation disagreement abstention。

### 5. Set Transformer

用 self-attention 表达集合元素交互，并用 inducing points 降低复杂度；迁移价值在于融合无序点、视角和候选集合，同时检查稀有部件是否被压缩。

**为什么能迁移：** 用 self-attention 表达集合元素交互，并用 inducing points 降低复杂度；迁移价值在于融合无序点、视角和候选集合，同时检查稀有部件是否被压缩。

**最危险错配：** 集合元素的相似度能代表几何关系，且固定数量 inducing points 覆盖长尾。对象数量变化、重复部件和视角质量差会导致记忆槽竞争。

**具体目标 pipeline：** 多视角 point proxies、遮挡者节点、候选 hidden proxies → ISAB 在各视角/部件集合上交互 → PMA 读取目标对象级状态 → decoder 输出完整 mask/occupancy。保持 observed nodes 的硬测量，unknown nodes 可输出多个 candidate slots。

**最小实验：** 用 50 个物体、多视角点集和随机遮挡，比较 Deep Sets、SAB、ISAB。保持参数与 FLOPs，扫 inducing 数 $m\in\{4,8,16\}$，测隐藏细杆召回、跨视角一致、可见误差和推理时间。阳性：小 $m$ 在同预算下提升；阴性：稀有细部被吞；无信号：集合交互不是瓶颈。

**反例与证据边界：** 一个细小但决定拓扑的杆只占总点数 0.1%，inducing points 被大平面主导；输出整体 CD 很好，杆却消失。 集合任务可以用 attention 表达关系，同时用 inducing points 扩展到更大集合。它并未保证 inducing memory 保留未知区证据，更不提供后验真值。

三项未运行 idea：Visibility-aware ISAB; Inducing budget sweep; Permutation/occlusion stress test。
