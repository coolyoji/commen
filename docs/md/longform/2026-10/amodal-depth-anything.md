## 1. 先说人话：它恢复的不是任意完整三维物体

【论文原文事实，§3.1，PDF p.3–4】输入一张被遮挡的图、它的普通深度估计、目标物体的完整轮廓 mask；输出目标物体被遮住部分的**相对深度**。普通深度图在被人挡住的椅子位置会描述“人离相机多远”，而这里要描述“假如透过这个人，椅子的对应表面在哪里”。

【基于证据的解释】这个任务比补完整轮廓多一个深度维度，但仍不是完整物体的内外体积或全部背面。一条相机射线上的目标深度，只给该视角下的一个表面位置；同一射线更后面的椅背背面、内部空腔和实体厚度没有因此被确定。**2.5D amodal depth、完整三维表面、实体占据是三种不同输出。**

核心直觉有三点：不用先把隐藏 RGB 画得漂亮再估深度，避免颜色补错把几何带偏；利用大深度模型已学到的形状知识，只补充“目标是谁、附近深度怎样”的条件；同时比较确定式与生成式深度模型。生成式参数化原则上允许随机输出，但**正式版没有系统验证固定输入下的多样性、真值覆盖率或概率校准**。Fig.8 展示 DAV2-L 随不同 mask 改变输出，不是同条件多采样证据。合理不等于真实，新增条件也不等于新增隐藏区域测量。

## 2. 摘要拆解：问题为什么存在，再追问一层

【论文原文事实，摘要、§1、§3.2】原文提出 ADIW 数据构造与 Amodal-DAV2、Amodal-DepthFM 两个分支。ADIW 从自然图像分割数据筛完整对象，再叠加遮挡物，用 Depth Anything V2 ViT-G 生成深度监督，报告约 564K 对样本。

【基于证据的解释】第一层原因不是单纯“遮挡很难”，而是**隐藏位置没有传感器测量，训练标签稀缺**。第二层原因是，即使能做大量 RGB 图像，人类也不能从那一张照片标出唯一真实深度；直接要求米制隐藏真值，会同时遇到不可观测性和标注成本。作者将任务改为相对深度，换取从自然图像伪标签学习的规模。这缓解监督获取，不消除隐藏结构的不可辨识性。

另一个问题是“先画图，再测深度”为何易错。第一层：补图器可能把椅背画成另一种轮廓，后级深度就跟着那幅假图走。第二层：生成 RGB 的目标偏向视觉合理性，不等于隐藏几何忠实；再经过相对深度估计，全图尺度/平移还可能改变。因此，两级都合理，也不保证组合结果对应原物体。见正式版 Fig.7 与 §4.3。

## 3. 相关工作为何不够、反向重建设计思路

【论文原文事实，§2、参考文献】Depth Anything V2 提供可见几何先验；DepthFM 提供快速条件流匹配深度生成；pix2gestalt 先补完整外观；Invisible Stitch 经 RGB/depth inpainting 构建新视图；Jo 等的 *Occlusion-aware amodal depth estimation for enhancing 3D reconstruction from a single image*（IEEE Access，2024）是直接 amodal depth 比较对象。

【基于证据的解释，非作者口述】若根本瓶颈是隐藏标签，第一步应改变数据获得方式，而不只是加大网络；若标签只有相对关系，训练应避免把未知的物理尺度强当已知；若目标是几何，就直接监督深度，减少 RGB 中介；若预训练已经学到大量形状知识，零初始化条件支路可避免一开始破坏原有映射。这是我们依据设计重建的推理路径，不是对作者真实心理过程的证明。

文献关系不是“本文首次解决遮挡”：已有 amodal segmentation 和 amodal depth。区别落在自然图像可扩展监督、相对深度表述及两类基础深度模型的适配。

## 4. 一张椅子图，走完整 pipeline

【教学构造，非新增论文案例】设一把椅子被桌面挡住。训练时先有较完整椅子的自然图，再粘一个前景物体形成遮挡图；教师分别估计原图深度和遮挡图深度。因为教师会随上下文改变深度的数值范围，先在共同可见的椅子部分拟合尺度与平移，将原图椅子深度映射到遮挡图的坐标范围；这给出“遮挡前可见、遮挡后不可见”的监督。

推理时输入 RGB、普通深度和完整椅子 mask。完整 mask 可由交互绘制或上游 amodal 方法提供，不是模型已经自行解决的步骤。DAV2 分支融合 RGB 与额外引导特征并直接输出；DepthFM 分支在 latent 中生成，再解码、在可见重叠区域对齐。两者不需要在隐藏区先合成彩色椅子。

### 每个模块的因果链

| 模块 | 输入证据 → 表示 → 训练信号 → 推理行为 → 结果 → 失效触发器 |
|---|---|
| ADIW | 原自然图与合成遮挡 → 教师深度对 → 可见区尺度平移对齐后的伪标签 → 学习“遮挡前后同一对象” → 大规模监督 → 教师错误、粘贴不物理、完整对象筛选误判 |
| DAV2 | RGB、观察深度、amodal mask → RGB/零初始化 guidance convolution 融合的 ViT 特征 → 全对象 scale-invariant log loss → 对目标区域直接回归 → 少一层 RGB 补图误差 → mask 错、教师域偏移、单值估计压缩多解 |
| DepthFM | 图像 latent、观察深度、mask → 条件速度场 → flow matching → 图像 latent 向深度 latent 的路径预测 → 隐藏深度输出 → 条件错误、解码尺度漂移；同条件多模式覆盖未系统核验 |
| 对齐 | 共同可见深度 → 两参数拟合 → 平方残差 → 校正生成深度范围 → 连接可见与隐藏部分 → 可见点太少、近似等深、错分割混入遮挡物 |
| 全对象监督 | 可见与隐藏目标区域 → 相同对象表示 → 两部分共同损失 → 学会几何连接而不只填洞 → 更稳的整体预测 → 可见区域占比大时可能掩盖小隐藏结构误差，需分区评估 |

这些链条是机制解释；消融只证明整体设计变化与指标变化相关，尚不能排除数据量、预训练及优化设置的替代解释。

## 5. 关键术语：直白，但不省略作用和失败

**Amodal / modal。** modal 是眼下真正看到的部分，amodal 包括被挡住却属于目标的部分。mask 告诉网络“这块位置应解释成椅子”，改变目标归属，而不是提供椅子背后的实测深度。移除 mask，模型容易返回当前前景表面；mask 扩得太大时，网络会被要求在本不属于椅子的区域生成深度。

**Scale-and-shift alignment，尺度—平移对齐。** 像两把刻度与零点都不同的尺，先在同一可见部分找换算关系，再用于隐藏部分。它解决相对深度数值规约不同，而非恢复米制距离。删除后，两张同形状深度图仍可能整体错位；若可见区域几乎是同一深度，只有一个窄取值范围，两参数拟合会病态，隐藏区外推可能剧烈变化。这个病态条件是我们的数学解释，原文没有做对应压力测试。

**Conditional flow matching，条件流匹配。** 学的是从图像 latent 向深度 latent 移动的方向，不是强化学习，也不需要奖励函数。时间位置和条件共同决定下一步；原文训练路径加入 Gaussian noise，不应仅据此声称已核验推理时的采样多样性。删去条件会让目标选择困难；确定回归与生成式参数化表达能力不同，但“表达可能多解”不等于“实测覆盖多解”。分布外结构仍可能得不到正确输出，多样性也不是正确概率。

**Silog。** 对数深度误差把成比例误差转成加性差，减去均值项削弱整体尺度影响。正式版用 λ=0.85，**不是**完全忽略尺度，更不是对加性平移也严格不变。把相对深度统称为“任意变化都无所谓”会误解损失。

## 6. 公式：来源、变量、优化行为

下列原式已与正式版 PDF p.4–5 画面核对；[原图裁剪和稳定 E 锚点](amodal-depth-anything-reader/paper.md#equations)可追溯。

**E001 / 原式(1)，p.4：**

$$
(s,t)=\operatorname*{argmin}_{s,t}\sum_{i\in M_{\mathrm{vis}}}(s d_i^b+t-d_i^o)^2.
$$

$d^b$ 是遮挡前教师深度，$d^o$ 是遮挡后深度；$M_{\mathrm{vis}}$ 排除真正被挡住的部分。只拿看得见的同一物体拟合，不拿隐藏真值偷看。拟合曲线成立还要求两张教师图在该对象上近似有共同仿射关系；上下文造成局部非线性扭曲时，两个参数不够。

**E002 / 原式(2)，p.4：**

$$
D_{\mathrm{aligned}}=sD_b+t.
$$

【基于证据的解释】将拟合推广到隐藏部分是一个外推假设。真实形状没变，不代表两个教师输出必然只差尺度和平移。

**E003 / p.5 无编号：**

$$
\mathcal L_{si}=\alpha\sqrt{\frac1N\sum_{i\in M_a}g_i^2-\frac{\lambda}{N^2}\left(\sum_{i\in M_a}g_i\right)^2},\qquad
g_i=\log\tilde d_i-\log d_i.
$$

$M_a$ 为完整对象 mask，$N$ 是有效像素数。损失在**完整对象**上算，评估主要在不可见区域算；不能把两者混同。可见部分参与训练，是为了让隐藏预测保留与已知对象的连接。

**E004 / p.5 无编号，保留原文范数写法，不擅自补平方：**

$$
\min_\theta \mathbb E_{t,z,p(x_0)}
\left\|v_\theta(t,\phi_t(x_0))-(x_1-x_0)\right\|,\qquad
\phi_t(x\mid z)=t x_1+(1-t)x_0.
$$

$x_0$ 在 §3.3.2 定义为图像编码，$x_1$ 是深度编码，$z$ 含图像、观察深度和 mask；训练另对路径样本加入 Gaussian noise。不要把这里机械改写成“任意纯噪声生成”的另一种 flow 版本。DAV2 整体微调，DPT 输入加 layer norm；DepthFM 第一卷积保留原8通道权重、增加两个零初始化条件通道。原文记号有 $M_o/M_a$ 与条件省略的局部不一致，读本标注，不替作者臆造精确定义。

## 7. 实验：先问问题，再看设计和答案

【论文原文事实，正式版 Table 1，p.6】评估不可见区域；RMSE 表内乘了 100，**不是米制误差**。

| 比较项 | Overall RMSE，表内数值 | 能支持的答案 |
|---|---:|---|
| pix2gestalt + 对齐 | 5.114 | 先补外观再估深度是可比较但非最优的路线 |
| Jo，原模型 + 对齐 | 6.939 | 未做同数据重训的对手 |
| Jo，同数据重训 + 对齐 | 4.712 | 更严格的适配对手；与上行不是同一基线 |
| Amodal-DAV2-S / L | 3.682 / 3.418 | 该验证集上 L 最好；不证明所有真实隐藏几何正确 |
| Amodal-DepthFM，未对齐 / 对齐 | 5.410 / 4.645 | 后处理对生成分支有帮助，但仍未超过 DAV2-L |

**百分比审计。** 正式版摘要写 50.7% RMSE 改善，正文 §4.3 写 27.4%。我们根据表格计算：(6.939−3.418)/6.939≈50.74%，(4.712−3.418)/4.712≈27.46%。两种数值可以由不同 Jo 基线得到；这是我们的算术解释，不冒充作者明确阐明了对应关系。预印本摘要另写 69.5%，不得拿来宣传正式版。错误不是“数字大才好”，而是省略比较对象会误导。

**为什么需要额外条件？** Table 2 的 S 模型去掉深度和 mask：7.549；只去 mask：4.369；完整：3.682。支持目标归属与场景深度条件都有用；没有排除同容量随机通道等替代解释。

**为什么全对象监督？** Table 2 仅隐藏区监督 3.845，完整对象 3.682。支持在该设置下加入可见部分有帮助；并不说明所有可见/隐藏损失比例都最优。

**为什么不能所有分支都加对齐？** DAV2-S 加对齐反而 3.878，差于 3.682；DepthFM 则 5.410→4.645。说明额外拟合可能修复尺度漂移，也可能引入拟合噪声。推理技巧必须看主干误差结构，不能当万能模块。

**看起来完整是否细节也正确？** p.8 的边缘实验报告 S 模型总体 3.682、边缘 7.378、非边缘 3.515。细结构是更难部分。不能仅从顺滑深度色图判断把手、轮廓和凹槽可靠。

## 8. 贡献与证据边界：为什么存在这些缺陷

【作者贡献】自然图像下的相对 amodal depth 任务、ADIW、两个适配框架。【已核验证据】正式版的构造流程、Table 1–3、Fig.3–8；官方仓库的推理文件和权重链接。【未核验】本机复现数值、完整训练数据可取得性、所有 checkpoint 与正式版是否一致、真实隐藏深度精度。

**伪标签的共同教师偏差。** ADIW 标签与观察深度来自 DAV2 ViT-G，Amodal-DAV2 又从 DAV2 初始化；DepthFM 从其自己的深度预训练模型初始化，不能把两支都说成 DAV2 学生。第一层：教师把某个曲面估平，监督就把“平”当答案。第二层：数据和评价共享相同几何观念时，模型更贴近教师不等于更贴近实物。两支受伪真值边界约束，但架构同源程度不同。这是潜在替代解释，不是指控数据泄漏；应换独立几何真值区分。

**Mask 错误为什么会级联？** mask 定义目标支持区域，错误轮廓会改变网络被要求补什么。对标签构造和采用推理对齐的 DepthFM，还可能改变可见区拟合的有效点；**默认 DAV2 直接回归，不做这一步推理拟合**。因此级联路径应分支讨论，不能把后处理风险泛化成所有分支的必经步骤。

**为什么贴图数据会有域差？** 真实遮挡与接触阴影、物体支撑和透视相关；随机粘贴能控制覆盖率，却可能没有这些共同生成因素。训练时通过边缘或粘贴痕迹认出“这里该补”，部署时就缺少该捷径。原文未量化此因果机制，属于需实验区分的解释。

**为什么单一深度不能保证完整三维？** 一个像素的目标深度没有编码同射线第二、第三个表面，更没有物体内外；相对深度还缺绝对尺度。这里是表示及可观测性限制，不是“训练时间再长一点”就会消失。

## 9. 迁移：把结构对应写清楚

| 目标 | 源机制与目标同构 | 必要条件 | 错配、改造与失败触发器 |
|---|---|---|---|
| amodal 补全 | 可见证据固定目标，先验推断隐藏部分 | 同一对象归属、可靠可见区 | 本文假定完整 mask 已给定；联合预测需显式 mask 不确定性，遮挡顺序错会把前景复制给目标 |
| 三维重建 | amodal 深度增加普通点图未涵盖的表面观测候选 | 内参、尺度锚点、视图一致性 | 相对深度不是米制；需尺度标定与实际视图约束，否则跨视角“各自合理”但拼不起来 |
| 三维 amodal 补全 | 可见锚点 + 学到的完整形状先验 | 多假设表示、可见/不可见分离、训练完整几何 | 单层深度不表达背面/内外；需多层射线、SDF/TUDF 或对象场。隐藏先验不得覆盖已见自由空间 |

【我们提出的研究假设】最有价值的连接不是“把深度图直接转 mesh 就结束”，而是把它作为**受观测约束的隐藏表面提议**。新视角、触觉或真实深度到来后，应允许该提议被推翻。UAV 还涉及大尺度、俯视、低视差和动态物体，不能直接继承自然图像结果。

## 10. ARIS：三个深层 idea，全部未运行、未确认新颖性

### Idea A：可见区到底够不够支撑隐藏区的仿射对齐？

【研究假设：检验隐含前提】真正危险因素可能不是可见比例，而是**可见深度的变化范围与空间分布**。

- 步骤：固定完整对象和遮挡面积，分别保留近似平面区域、跨多个深度的区域、只保留边缘；比较 s/t 的方差和隐藏深度误差。再加入少量 mask 泄漏，判断是几何退化还是错误匹配先失效。
- 最小实验：20–50 个有真实完整深度的合成/多视图对象，使用现成预测或直接控制教师对；先 CPU 解两参数拟合，最多一周内完成诊断，不重训主干。
- 阳性：同可见比例下，深度分布窄的误差显著增大，支持条件数诊断；阴性：退化区也稳定，检查模型先验是否主导而非对齐；无信号：先确认干预是否真正改变可见深度跨度。
- 贡献：把“遮挡百分比”改为可测的几何可辨识性；风险：合成深度过于干净，需真实对照。关系：超出原文按 visible ratio 分组的测试；不是作者结论。

### Idea B：把教师一致与真实几何正确拆开

【研究假设：反事实与失败诊断】学生可能主要复现标签教师的形状偏好。

- 步骤：同一 RGB 的标签分别来自 DAV2、独立深度估计器与真实几何；固定 mask，比较教师间一致区/分歧区，加入平面、细杆和凹槽组。
- 最小实验：不重训先分析发布模型对独立真值的残差，并计算残差与各教师错误的相关性；20 个对象就可发现明显分歧，但不能据此作全局统计结论。约 3–5 天，推理成本随权重显存而定。
- 阳性：在分歧区更贴近教师却更偏离真值，支持教师偏差解释；阴性：对真值持续更准，削弱该解释；无信号：可能几类参考都犯同一错误，应增加结构不同的真值。
- 贡献：审计几何监督的证据独立性；风险：相机/尺度对齐误差混入结果。关系：挑战 ADIW 评价能支持多强几何主张，不把未验证风险写成已存在作弊。

### Idea C：可证伪的三维 amodal，而不是一张最终深度图

【研究假设：连接三维任务】将可见表面和观测自由空间硬保护，只在未知空间生成多候选，再让新视角排除错误候选。

- 步骤：用相机和可信深度划分 observed/free/unknown；把本文预测当隐藏表面提议，转换为多层或对象距离场；对多采样输出逐一重投影；输入第二视角后重加权而非无条件平均。
- 最小实验：10 个有多视图真值的对象，固定两视角，比较可见面误差、隐藏 coverage、自由空间违例与候选多样性。第一周仅验证流程，不承诺完整网络训练。
- 阳性：第二视角排除错误背面且不伤害已见几何，支持分账；阴性：所有候选都缺真形状，说明先验支持不足；无信号：检查第二视角是否实际揭示了歧义。
- 贡献：把“补全”定义为随证据可更新的假设集合；风险：相机误差错删真候选、生成模式坍缩。与原文关系：把 2.5D 隐藏深度先验推广为三维证据更新，不是本文已证明的迁移。

## 11. PaperForge 收敛：复现、强反例、非增量方向

【一周最小复现】先运行作者推理例子并记录依赖/权重版本；固定20张图核对输入mask与输出；复做 mask 扰动和可见区对齐诊断；复算选定 Table 1 的指标定义。训练用4张 A100 是原文条件，不等于本机具备该预算；本轮只写计划，没有下载模型、配置训练或开 GPU。

【最脆弱前提】两支都依赖正确的目标支持和有效的几何先验。训练标签构造及 DepthFM 推理对齐还依赖可见区丰富、教师误差近似仿射；两张教师深度先缩放至[0,1]后再拟合。DAV2 推理不显式拟合，不应将拟合退化当成它的必经步骤。

【最强反例】两个对象从输入视角有完全相同 RGB、可见深度和完整投影轮廓，却有不同的背面厚度/凹腔。系统输入无法区分，任何唯一输出都不可能对两个对象同时是真值。反例否定的是“单图确定真实完整形状”的过强主张，不否定论文作为相对深度先验的价值。

【非增量方向】研究“下一条证据必须观测哪里，才能消除现有隐藏几何分歧”，将生成、主动视角与触觉统一为可辨识性问题；不要只在现有骨干上再叠一个 attention 模块。

## 12. 深层诊断卡与精读结论

| 项目 | 诊断 |
|---|---|
| 表面症状 | 遮挡后几何空缺、先补RGB再估深度出现级联错误 |
| 第一层根因 | 隐藏标签缺失、上下文改变相对深度规约、目标mask不确定 |
| 第二层根因 | 单图多解；RGB生成目标与几何忠实错配；教师与评价共享偏差 |
| 方法作用点 | 可扩展伪标签、可见区对齐、几何条件、全对象监督 |
| 隐含前提 | mask支持正确、教师仿射关系近似成立、可见区足够有信息 |
| 失败触发器 | 近等深可见片、mask泄漏、罕见拓扑、细边缘、域外粘贴关系 |
| 迁移必要条件 | 尺度/相机锚点、跨视角一致、显式区分观测与生成 |
| 反证实验 | 固定遮挡比例改变可见深度分布；独立真值教师审计；同输入异背面 |
| 证据边界 | ADIW相对隐藏深度与有限自然图像展示；未证明真实完整三维、校准不确定性或任意开放域 |

**真正留下的结论：**本文说明，目标级深度先验与正确的监督构造，比单纯先画出隐藏颜色更贴近 amodal 几何问题。但它也提醒我们：**能生成隐藏形状，和拥有决定该形状的证据，是两件事。**后续实验应优先区分这两者，而不是只比较一张完整程度更高的图。
