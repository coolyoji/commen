## 精读｜3D Gaussian Splatting

3DGS 的核心价值是把显式局部表示、可见性排序、光度梯度和实时渲染放在同一个闭环里。深层迁移问题不是“Gaussian 能不能补全”，而是没有射线证据时，density control 会不会把真实隐藏结构当成低价值元素删除。

### 精读 ARIS 摘要

### 精读 ARIS 摘要：3D Gaussian Splatting

**真实问题与缺口。** 论文解决多视图场景的实时、高质量渲染；更深层缺口是表示和渲染器让观测梯度昂贵。它没有解决未观测表面不可辨识。

**为什么需要方法。** 3D Gaussian、各向异性协方差和 tile rasterizer 共同减少空空间采样与冗余点；单独换网络无法消除射线积分成本。

**为什么可能有效。** SfM 点提供可观测初始化，Gaussian 把局部方向容量写入 `Σ`，alpha 合成提供可微图像形成，density control 把预算放到高梯度区域。前提是相机、对应和训练视角可靠。

**未解决缺口。** 隐藏表面没有光度梯度，密度控制可能删除真实但未见结构；PSNR/SSIM 不覆盖拓扑、实体闭合或隐藏真值。

**三条 idea。** 1）证据类型感知 density control；2）几何—外观反事实诊断；3）可撤销的多候选 Gaussian amodal 状态。三者均未运行，最小实验、阳性/阴性/无信号解释见 [精读长文](../longform/2026-11/3dgs.md)。

## Masked Autoencoders Are Scalable Vision Learners

出处：[arxiv:2111.06377](https://arxiv.org/abs/2111.06377)；源领域：自监督学习与结构化缺失建模；方法家族：高比例 patch masking、非对称 encoder-decoder。

### 泛读：Masked Autoencoders Are Scalable Vision Learners

**先说人话。** MAE 随机遮掉约 75% 图像 patch，只把可见 patch 送入 encoder，再用轻量 decoder 恢复像素。它证明“缺很多”可以成为强的自监督信号，但训练缺失是随机 patch，真实遮挡往往由物体形状、相机和遮挡者共同决定。

**摘要与术语。** asymmetric encoder-decoder 解决的是计算浪费：encoder 不处理 mask token；mask token 只在 decoder 端补回位置。高 mask ratio 让任务不能靠局部纹理复制，迫使表示保留全局结构。删掉非对称结构会把大部分算力花在无信息 token 上；删掉高比例遮挡，预训练可能退化成局部纹理插值。证据边界是 ImageNet 预训练和下游迁移，不是 amodal 真值恢复。

**方法流程与因果链。** 图像 → patch embedding → 仅可见 token 的 ViT encoder → 拼回 mask token → decoder → 像素重建损失。训练信号是完整原图像素，推理时只提供可见 patch。根因链是：随机缺失让模型学习跨 patch 的统计依赖；但如果真实缺失是 MNAR（细杆、背面、被遮挡部分更容易缺失），训练分布就没有学习“缺失机制”。因此 MAE 能迁移的不是随机 mask 本身，而是“让表示在证据缺失时仍保留全局结构”的训练范式。

**为什么可套用到非模态补全。** 源变量是可见 patch `V`、隐藏 patch `H` 和完整图像 `X`；目标变量可换成可见目标 mask、unknown 区和完整 mask/SDF。具体改造：输入三态 mask（visible/occluder/unknown），encoder 只读 visible 与确定自由空间；decoder 输出隐藏 mask、深度或 occupancy，并加可见区域硬一致性和跨视角重投影损失。最危险错配是把遮挡物 patch 当负样本，或用随机遮挡训练却在结构相关遮挡测试；这会让模型把“看不见”错误解释成“背景”。

**最小判别实验。** 固定 ViT 参数和 token 预算，对照随机 patch MAE、按形状相关机制生成的 mask MAE、删除 unknown 三态的版本；在同可见比例下测隐藏 IoU、可见约束违约、细结构召回和跨视角一致性。阳性：只在机制匹配的训练遮挡上改善；阴性：改造无益说明瓶颈在形状先验或几何表示；无信号先检查 mask 是否泄露完整标签。

**ARIS ideas（均为研究假设）。**

1. **MNAR-预训练诊断：**同可见率比较随机、块状、由遮挡者深度决定的 mask；假设差距来自缺失机制而非比例。最小实验用合成完整 mask，阳性是机制匹配时隐藏区下降，阴性说明低阶上下文足够，无信号检查任务难度。
2. **三态 decoder：**visible/occluder/unknown 三路 token，unknown 只接受完整形状和跨视角监督；对比二态 MAE 与去掉 occluder 通道。预期贡献是避免伪负监督；风险是三态标签噪声把错误证据放大。
3. **反事实读出：**同一 latent 分别做像素平均、候选 mask、SDF 候选读出；检验平均会不会产生不存在的拓扑。阳性为平均拓扑断裂而候选合法，阴性说明任务近似单峰。

**PaperForge 十二段式压缩结论。** 问题：缺失输入下如何学全局表示；相关工作不够：普通自编码器在算力与局部捷径上失衡；作者思路：高比例遮挡+非对称结构；直觉：只看证据、再用轻 decoder 补齐；真实 pipeline：可见 patch→latent→mask token→重建；公式核心是 patch 重建 MSE；实验回答 ImageNet 迁移是否提升；真正结论是预训练表示更强；脆弱前提是随机遮挡足以覆盖目标缺失机制；一周复现是低分辨率形状 MAE；最强反例是背面类别完全不可辨识；非增量后续是显式学习遮挡选择机制并输出多候选。

**深层诊断卡。** 表面症状：随机 mask 预训练在真实遮挡上掉点；第一层根因：训练缺失和部署缺失不匹配；第二层根因：目标变量是结构相关缺失且未知区多解；作用点：mask 语义、decoder 读出和硬一致性；失败触发器：遮挡者错分、跨视角错配、细结构长尾；反证实验：同可见率不同缺失机制配对；证据边界：原文证明自监督迁移，不证明 amodal 完整真值。


## Deep Sets

出处：[arxiv:1703.06114](https://arxiv.org/abs/1703.06114)；源领域：集合函数与点云/无序观测；方法家族：permutation-invariant/equivariant set representation。

### 泛读：Deep Sets

**先说人话。** Deep Sets 给出对无序集合做学习的基本结构：先对每个元素共享编码，再求和/池化，最后用解码器处理聚合结果；若输出也需要逐元素对应，则使用 permutation-equivariant 结构。它解决的是“输入顺序不应改变答案”，不是缺失观测本身。

**两层根因。** 第一层是将点云、观测射线或候选部件强行排成序列会让模型学到假的位置偏好；第二层是当观测数量变化、相机顺序变化或多视角到达顺序变化时，这种假序关系会污染隐藏形状推断。Deep Sets 的归纳偏置把顺序不变性写入表示，但它不提供几何邻接、射线顺序或遮挡深度。

**方法因果链。** 无序观测集合 `{x_i}` → 每个元素共享 `φ(x_i)` → 求和/平均得到全局统计 → `ρ` 输出目标。若要输出每个点的补全标签，则加入全局聚合与该点特征的 equivariant 组合。删除共享编码，模型会把元素身份混入参数；删除对称聚合，输入排列会改变结果。表达定理只说明函数形式，不保证从部分点识别真实背面。

**迁移方案。** 目标输入是带相机、深度、可见性和置信度的观测集合；每个元素对应一条射线、一个可见表面 patch 或一个部件 token。先用 `φ` 编码观测，再以相机坐标/射线方向做几何条件聚合，输出完整 mask/SDF 的查询点分布。二维 amodal 适合防止检测顺序泄露；三维重建可处理可变视角数；三维 amodal 仍需额外的形状先验和跨视角对应。最危险错配是直接求和丢掉射线深度顺序或相机关系。

**最小实验。** 同一数据、参数和观测数，对照按输入顺序的 Transformer、Deep Sets、加入相机/深度的 equivariant 版本；随机打乱视角并测输出方差、隐藏 Chamfer、跨视角一致性。阳性是打乱不改变预测且几何误差下降；阴性说明顺序不是瓶颈；无信号检查网络是否偷用了固定 slot 或 batch 顺序。

**ARIS ideas（研究假设）。**

1. **观测集合等变性检查：**训练时随机排列多视角，测试对排列做全排列/随机扰动；假设顺序敏感是现有系统的隐藏错误。最小实验报告预测差与隐藏误差；风险是相机 token 本身编码了顺序。
2. **几何条件聚合：**把 `φ(x_i)` 改成观测、射线方向、深度置信度三元组，并比较去掉方向/深度的消融。阳性说明集合不变性必须与几何条件并存；阴性说明任务主要由外观统计决定。
3. **候选集合而非单向量：**让全局聚合输出多个 shape slots，每个 slot 是一个完整候选；比较均值向量和候选集合。若候选覆盖提升而均值拓扑变坏，说明 Deep Sets 需要和多解读出结合。

**PaperForge 压缩结论。** 问题是无序输入的函数表示；相关工作不足在于固定长度/序列假设；作者思路是交换性定理→共享编码→对称聚合；核心公式 `f(X)=ρ(Σφ(x))`；实验验证集合统计、点云和异常检测；真正结论是结构化不变性而非缺失恢复。最脆弱前提是元素间关系可由对称聚合充分表达；最强反例是两个相同局部但不同射线深度的观测；非增量后续是将集合不变性和可见性图/三维查询结合。

**深层诊断卡。** 症状：视角顺序变化导致补全变化；第一层根因：模型把序列位置当证据；第二层根因：没有把“无序”与“几何关系”分开表示；作用点：共享编码+带相机条件的聚合；失败触发器：重复纹理、遮挡顺序缺失、候选多解；反证：全排列一致性与相机置换对照；证据边界：原文证明集合函数结构，不证明三维完整性。


## Object-Centric Learning with Slot Attention

出处：[arxiv:2006.15055](https://arxiv.org/abs/2006.15055)；源领域：对象中心表示与组合推理；方法家族：exchangeable slots、竞争式注意力、迭代绑定。

### 泛读：Object-Centric Learning with Slot Attention

**先说人话。** Slot Attention 把 CNN/ViT 特征竞争式地分配到一组 exchangeable slots，每个 slot 逐渐绑定一个对象或对象部件。它的迁移价值在于：非模态补全不是把所有可见像素混成一个向量，而是要把“目标、遮挡者、背景和可能的隐藏部件”分开。

**两层根因。** 第一层是全局特征把不同物体的证据混合，遮挡边界处尤其容易把遮挡者纹理写进目标；第二层是没有对象级变量时，网络无法表达“这一部分属于同一个实体但当前不可见”。Slot Attention 通过竞争和迭代绑定引入对象级瓶颈，但 slot 身份是交换的，不能自动成为稳定的物理部件 ID。

**因果链。** 图像特征 → attention logits 与 slot 竞争 → GRU/MLP 迭代更新 → 每个 slot 解码成对象/部件 → 重建或属性预测。训练信号若只是重建，slot 可以学成纹理簇而不是实体；若加入遮挡可见性和完整形状监督，slot 才可能承担“同一物体的可见/未知部分”。

**迁移方案。** 输入 RGB、可见 mask、遮挡者 mask、深度/相机；固定若干 object slots，再为高不确定区域分配 hidden-part slots。可见区域通过投影/重建监督，隐藏区域通过完整 mask/SDF、跨视角和部件关系监督。二维 amodal 可让目标 slot 解码完整轮廓；三维重建需把 slot 绑定到 3D primitives；三维 amodal 要保留多个 hidden slots 并防止把不同候选平均成一个物体。最危险错配是 slot 竞争把同一物体拆成颜色块，或把两个相似物体合并。

**最小实验。** 在同一合成场景上对比普通 ViT、Slot Attention、带可见性监督的 Slot Attention；报告目标归属、遮挡者泄露、隐藏 IoU、部件一致性和 slot 稳定性。阳性是遮挡者纹理泄露下降且同一物体跨视角 slot 对齐；阴性说明对象中心瓶颈未解决几何；无信号检查 slot 数量与评估匹配是否造成虚假收益。

**ARIS ideas（研究假设）。**

1. **可见—隐藏双 slot：**每个对象分成 observed slot 和 latent-completion slot，后者只受完整形状/跨视角损失约束；测试是否减少遮挡者污染。阴性若隐藏 slot 只学类别原型，说明监督不足。
2. **slot 置换/干预诊断：**固定图像特征，交换目标和遮挡者 slot，测输出是否随实体改变；若交换不影响结果，说明 slot 只是装饰而非推理变量。
3. **三维部件绑定：**slot 解码到带可见性标签的 3D Gaussian/occupancy primitives，比较无 slot 的同容量表示；阳性是新视角下部件身份和隐藏结构更稳定，风险是固定 slot 拓扑排除新部件。

**PaperForge 压缩结论。** 问题是分布式表征缺少组合对象；方法用交换 slot 和竞争注意力建立对象瓶颈；核心直觉是让一个 slot 负责一个可重用实体；真实 pipeline 是特征→slot→对象解码→重建/属性；实验回答无监督对象发现和组合泛化；真正结论是对象中心表示可形成，不等于因果对象真值。最强反例是同色相邻物体或可见区相同、隐藏区不同的实例。非增量后续是把 slot 当成可被新视角否证的实体假设，而不是静态聚类。

**深层诊断卡。** 症状：遮挡边界把背景纹理写进目标；第一层根因：全局特征混合；第二层根因：没有显式实体变量且重建损失容许纹理捷径；作用点：竞争绑定、可见性条件和隐藏 slot；失败触发器：实例同质、slot 数量错、动态部件；反证：slot 交换与跨视角身份一致性；证据边界：原文验证对象发现，不证明 amodal 真实背面。


## Deep Variational Bayes Filters: Unsupervised Learning of State Space Models from Raw Data

出处：[arxiv:1605.06432](https://arxiv.org/abs/1605.06432)；源领域：时序隐状态与变分滤波；方法家族：Deep Variational Bayes Filter、可微状态转移。

### 泛读：Deep Variational Bayes Filters

**先说人话。** DVBF 学一个带潜在状态的非线性状态空间模型：观测图像只是状态的投影，状态按可微转移演化。它适合解释视频中“当前被挡住，但过去或未来曾经看见”的情况。

**两层根因。** 第一层是逐帧补全忽略时间，导致同一物体的隐藏部分在不同帧漂移；第二层是没有显式状态转移时，模型可以用每帧独立的外观捷径解释观测，无法区分真实运动和遮挡造成的表观变化。DVBF 通过变分后验和可反传 transition 把长期一致性写入 latent，但变分后验仍可能把错误身份锁定。

**因果链。** 观测序列 → encoder 得到近似状态后验 `q(z_t|x_{\le t})` → 可微 transition `p(z_t|z_{t-1})` → decoder 重建下一帧/当前帧 → ELBO/预测损失。删除 transition，latent 会退化成逐帧编码；删除不确定性，单点状态会在长遮挡中自信漂移。原文验证的是状态空间学习和长期预测，不是遮挡物体完整几何。

**迁移方案。** 把状态 `z_t` 改为“对象位姿 + 可见表面 + 隐藏形状候选 + 置信度”；输入每帧 RGB、可见 mask、相机和检测置信度。transition 只更新可运动变量，隐藏形状用 persistence/shape prior 保持；新显露区域作观测更新。二维 amodal 可约束 mask 跨帧一致；三维重建可把相机和深度纳入状态；三维 amodal 需要多候选 belief state，不能把 posterior mean 当真背面。最危险错配是时间对应错误或动态形变超出 transition 支持。

**最小实验。** 合成一个有遮挡—再显露序列，比较逐帧模型、DVBF 式状态模型、去 transition 消融；固定参数与帧数，报告长遮挡期间的隐藏误差、再显露后的更新速度、身份交换率和不确定性覆盖。阳性是状态模型在遮挡后可快速校正；阴性说明视频没有新增证据或 transition 过强；无信号检查未来帧泄露。

**ARIS ideas（研究假设）。**

1. **再显露反证：**在遮挡中保持形状候选不变，物体再次显露后只更新被证据触及的部分；假设比每帧重采样更少漂移。阳性为再显露误差骤降且已见面不变。
2. **多候选 belief：**维护 K 个隐藏形状状态，按新帧 likelihood 重加权；比较 posterior mean、单候选和多候选。阳性是同正面异背面时覆盖提升；阴性说明数据近似可辨识。
3. **转移反事实：**人为打乱帧顺序或替换运动模型，测输出变化；若模型对顺序不敏感，说明它没有真正使用状态转移。

**PaperForge 压缩结论。** 问题是从图像序列学隐状态；方法把变分推断、可微 transition 和 decoder 组合；实验回答长期预测是否改善；最脆弱前提是 Markov 状态足以总结过去，最强反例是身份交换/非刚体突然变化。非增量方向是“可被新观测否证的 amodal belief filter”，而非只把视频 encoder 换大。

**深层诊断卡。** 症状：长遮挡后形状漂移或身份跳变；第一层根因：逐帧预测无记忆；第二层根因：状态、观测和身份对应不可辨识；作用点：transition、belief 多样性和再显露更新；失败触发器：快速形变、相似实例、错相机；反证：帧乱序/新视角重显露；证据边界：原文支持状态空间学习，不证明隐藏几何可识别。


## Learning to Explore using Active Neural SLAM

出处：[arxiv:2004.05155](https://arxiv.org/abs/2004.05155)；源领域：机器人主动感知与层级探索；方法家族：可学习 SLAM、全局/局部策略、解析路径规划。

### 泛读：Learning to Explore using Active Neural SLAM

**先说人话。** Active Neural SLAM 把探索拆成学习的 SLAM、全局策略、局部策略和解析路径规划。系统不是被动等新视角，而是选择下一步去哪里，以减少地图未知并完成目标。

**两层根因。** 第一层是单视角 amodal 的未知区可能有多个解释；第二层是继续在原视角堆算力并不会增加信息，真正缺的是能区分候选的观测。主动感知把“补全不确定”改成“选择能最大减少不确定的动作”。但原任务的目标是可达/探索覆盖，不是完整物体真值，信息增益必须重新定义。

**因果链。** 当前 RGB/深度/位姿 → 神经或几何地图 → 全局 frontier/目标价值 → 局部策略 → 解析路径与动作 → 新观测更新地图。删掉地图状态，策略退化为反应式；删掉可达性约束，信息增益动作可能不可执行。迁移到 amodal 时，目标价值应由候选形状之间的预测分歧、可见表面缺口和风险预算共同决定。

**迁移方案。** 对 UAV/机器人，输入当前可见 mask、深度、相机和 K 个隐藏形状候选；候选分歧最大的可达视角作为 action，采集 RGB-D 后只更新被新射线触及的区域。二维 amodal 可用小幅视角/摄像机移动验证轮廓；三维重建天然适合主动视角；三维 amodal 需把信息增益和动作成本、动态变化、遮挡者运动一起优化。最危险错配是用“地图覆盖率”替代“形状可辨识度”，绕远路却没有淘汰候选。

**最小实验。** 在 10 个具有同正面异背面的合成对象上，比较随机视角、最大可见面积视角、最大候选分歧视角；固定动作数和路径长度，报告隐藏 Chamfer 下降、候选淘汰率、可见面保持率和总移动成本。阳性是分歧策略在相同成本下减少不确定性；阴性说明新增视角无法区分候选；无信号检查视角是否真正暴露隐藏差异。

**ARIS ideas（研究假设）。**

1. **候选分歧导航：**把 action value 定义为新视角下候选渲染的预测分歧，而非只看 frontier 面积。阳性为相同步数获得更低隐藏误差；风险是分歧可能来自颜色噪声。
2. **主动反例预算：**每次动作前预测“哪类候选会被证伪”，动作后检查是否真的淘汰；若连续动作没有减少候选，应触发拒答而非继续探索。
3. **动态场景策略：**把遮挡者运动和相机成本放入状态，比较静态信息增益与风险敏感策略；阴性结果也能说明静态规划不能直接迁移到 UAV 视频。

**PaperForge 压缩结论。** 问题是探索与地图构建的样本复杂度；方法用层级策略和解析规划降低端到端学习成本；实验回答模拟环境中探索效率和 PointGoal 转移；最脆弱前提是地图状态和动作执行可靠。最强反例是所有可达视角都看不到目标背面，信息增益为零但策略仍需停下。非增量方向是把“补全—主动观测—候选淘汰”作为一个可拒答闭环。

**深层诊断卡。** 症状：模型在原视角自信，却无法判断隐藏结构；第一层根因：观测不足；第二层根因：没有把动作选择绑定到候选可辨识性；作用点：地图状态、候选分歧和可达规划；失败触发器：动态物体、动作成本、不可达视角、错误位姿；反证：固定步数下分歧视角不优于随机；证据边界：原文证明探索策略，不证明 amodal 候选真值。


## 本批迁移结论

五篇泛读并不是把五个模型直接套到非模态补全，而是分别补五个缺口：MAE 处理结构化缺失的训练信号；Deep Sets 处理多视角无序输入；Slot Attention 处理对象与部件归属；DVBF 处理遮挡时的时序状态；Active Neural SLAM 处理是否值得获取新证据。共同边界是：若未知区域不可辨识，任何方法都只能输出候选、风险或主动观测计划，不能把合理生成写成真实恢复。
